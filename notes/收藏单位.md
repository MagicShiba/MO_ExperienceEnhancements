# 选中单位收藏

代码: `src/gui/Favorite.cpp` (状态/绘制)、`src/gui/UnitPanel.cpp` (按钮列)。
入口: 左下角选中面板左侧的星星按钮，自下而上第 3 个起是收藏槽 `1..4`。

## 1. 按钮逐个露出

面板左侧固定两个按钮 (折叠 / 操作模式)，之后是收藏槽。默认只显示 1 个收藏
按钮；某个槽**收进过东西**之后，才多露出下一个，最多 4 个：

```
用掉槽 1 → 露出槽 2 → 用掉槽 2 → 露出槽 3 → … → 4 个封顶
```

`s_Reveal` 只增不减：清空收藏只清槽内容，按钮不收回去 (槽显示同色暗星)，
免得位置天天变。换图/换局时连收藏一起清空，`_Reveal` 回到 1。

## 2. 点击语义

| 操作 | 结果 |
|---|---|
| Ctrl + 左键 | 把**整组**当前选中集收进该槽 (已用槽直接覆盖)，露出下一个槽 |
| 单击 (松开时未到 `HoldMs`) | 镜头跳到该组中心 |
| 长按 (按住超过 `HoldMs`) | 清空该槽 |

按下沿只记起点 (`Fav_PressBegin`)，真正的动作在 `Fav_PressPoll` 结算：
按住到 `HoldMs` 就清空并标记本次已处理，之后松开不再跳转；先松开则跳转。
Ctrl 在按下沿直接收藏，不参与长按。计时用墙钟 (`GetTickCount`，不是逻辑
帧 —— 逻辑帧在暂停/卡顿时会停，长按窗口就失真了)。

单击不再需要双击窗口，所以 `DblMs` 与"挂起取消"整套都删了。

## 3. 组与验活

一个槽存一整组 `{ObjectClass*, Fetch_ID}`，上限 `GroupMax` (默认 64，超出部分
丢弃并记 `trunc=` 日志)。每帧 `Fav_Poll` 剪枝: `IsAlive`、非 `InLimbo`、
血量 > 0，再用 `OU_PtrAliveRaw` 按 `Fetch_ID` 索引反查一遍兜指针复用。索引
取不到 (`id==0`) 就只留字节判据，不因此丢收藏。成员死光 ⇒ 槽变空槽。

## 4. 星星与箭头 (分两趟画)

- 每个存活成员头顶画一颗 13x13 五角星，颜色按槽位: 绿 / 黄 / 红 / 青
  (`Color1..Color4`，0xRRGGBB)。星先铺一圈深色描边再压彩色芯 —— 雪地/亮
  地形上单色星看不见。
- 高度取 `单位坐标 + LiftLeptons` 后走引擎投影 (`OU_ProjWorld`)，投影后再
  上移 `StarLiftPx` 像素 (默认 25)。leptons 那段跟着缩放走，像素那段微调
  贴地/建筑高矮不一致时的观感。
- **星星画在 UI 层之前** (`Fav_DrawStars`，在消息帧的地图/天气之后、
  `MOE_DrawUILayers` 之前)：超武侧栏、超武面板、选中面板都能盖住星，星不会
  糊在面板上。**箭头相反** (`Fav_DrawArrows`，UI 层最后)：离屏指示必须始终
  看得见。
- **黑幕里不画**: 成员所在格 `CellClass::AltFlags` 的 bit3 (`CELL_SHROUD_
  REVEALED`) 没置就不画星；**每个**离屏的已揭示成员各给一个同色箭头
  (`Fav_DrawSlotArrows`)，不再只画组质心一个。
- 一槽离屏箭头超过 `ArrowLite` (默认 15) 个时，该槽所有箭头按一半不透明度
  画 (`alpha=128`)；超过 `ArrowMax` (默认 40) 个时，多出的不画。两者都按槽
  独立计，避免 50 个单位的组把屏幕糊满。
- `ArrowMode=edge` (默认): 射线与内缩 `ArrowInset` 的视图矩形求交，箭头贴
  屏幕边缘。
- `ArrowMode=center`: 以视图中心画同心圆轨道，槽 `0..3` 依次用半径
  `CenterRadius + 槽号 × CenterGap`；同槽的多个箭头都在自己那圈上按各自
  目标方向滑动，四个槽各占一圈、不会重叠。视图太小时自动压缩圈距并夹到
  视图内。右键点任意星星按钮可在两种模式间实时切换 (只改运行时状态，
  不回写 ini)。

## 5. 通信信标箭头

`Fav_DrawBeaconArrows` 给**离屏**的通信信标 (B 键放置) 也画箭头，颜色取该
信标所属玩家：`HouseClass::ColorSchemeIndex` → `ColorScheme::Array[..]` 的
`Colors[MainShadeIndex]`（与 ESC 玩家色色块、单位颜色同一套）。摆位复用同一
套 `ArrowMode`：

- `edge`: 贴视图边缘，与收藏箭头同一圈；
- `center`: 接在收藏四槽外面，即半径 `CenterRadius + (4 + 圈号) × CenterGap`；
  两个信标落到同一点附近时，后一个往外多走一圈 (`ArrowSize + 6` 像素的间隔)
  错开，最多加 8 圈。

只画本机看得见的信标：先调引擎 `BeaconClass::VisibleToPlayer 0x4308B0`
(只读：已放置 + 与本家同盟 + 该房可见)，再叠本地黑幕判据 —— 敌方信标不能
靠箭头把位置漏出来。信标上限 8 房 × 3 槽 = 24 个，所以不设透明度/上限那套
阈值。开关 `BeaconArrow` (默认 1)。

## 6. 跳转

组质心 (存活成员坐标平均) → `TacticalClass::SetTacticalPosition`
(`0x6D6070`，`__thiscall (CoordStruct const*)`)。Z 用 `OU_SurfaceZAt` 取
地面高度，不拿飞行单位的 Z —— 否则视口会偏到天上。

只动本地摄像机，不写模拟、不发事件，联机安全。收藏/按住状态/星星全是本机
状态，其它玩家看不到、也不参与模拟。

## 7. 配置

```ini
[Favorite]
Enable=1
HoldMs=600
LiftLeptons=150
StarLiftPx=25
ArrowMode=edge
ArrowInset=16
CenterRadius=36
CenterGap=26
ArrowLite=15
ArrowMax=40
ArrowSize=11
BeaconArrow=1
GroupMax=64
Color1=0x40E060
Color2=0xFFD040
Color3=0xFF4838
Color4=0x40D8F0
```

## 8. 日志

`fav: enable=/hold=/lift=/arrow=/lite=/max=/bc=/grp=` 启动配置；`fav: store slot N
n= trunc= reveal=` 收藏 (Ctrl+左键)；`fav: store skip (no selection)` 没选中；
`fav: clear slot N` 长按清空；`fav: jump slot N` 单击跳转；`fav: arrow=center|
edge` 右键切换箭头类型；`fav: slot N -> M` 剪枝后的成员数；`fav: reset
(scenario)` 换图清空。
