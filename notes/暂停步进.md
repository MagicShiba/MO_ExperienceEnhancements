# 单机暂停与单步帧进

需求: 单机暂停模拟, 画面仍可移动查看; F5 + 两按钮 (暂停/恢复, 单步一帧)。

## 做法 (MainLoop 入口迷你循环)

* 入口门 `0x55D360` (首 5B = `mov al,[IsActive]` 单指令, 跳板安全):
  暂停且无步进 → 跑迷你循环后跳 `0x55DEDB` (ret) 出本轮;
  步进帧入口扣数放行一轮原循环。Logic/帧存/限速整轮不跑。
* 迷你循环: CallBack → 焦点/对话框守卫 → MarkNeedsRedraw(2) →
  GetInputAndUpdate(3 出参) → KeyboardProcess → Render → Tactical::Update
  → Sleep(1)。输入/渲染/Tactical 照转, 视角原生可动。
* 迷你循环调 Mark 走 `0x4F42F0` 钩子入口, 全部 Poll 在暂停中照跑;
  Poll 内无 Mark 调用, 无递归。
* 地址 (YRpp 实证): CallBack=`0x48D080`, KeyboardProcess=`0x55DEE0`,
  IsActive=`0xA8E9A0` / IsFocused=`0xA8ED80` / SpecialDialog=`0xA8EDA0`,
  Render=`0x4F4480`, Map=Display=`0x87F7E8`, Tactical 虚表`+0x5C`,
  EAX 经 regs+`0x24` 回填。

## 配置 ([BottomBar])

* `PauseEnable=0` 整个不启用; `=1` 启用但按钮默认隐藏,
  按一次 F5 暂停后长久显示。
* `PauseHotkey=F5` (OU_Hotkey 语法)。

## 联机安全

* `GameMode==3/4` 或未开局时入口门恒放行。只读 + 渲染面写入;
  暂停态不进存档; 不可暂停态与换图强制复位 (帧号倒退或 Scenario 指针
  变化, 指针会被引擎复用, 单判不可靠)。

## 钩子铁律

* 禁止钩 `E8 call`: Syringe 跳板不修正 `rel32`, 落点跳飞。
* `GetInputAndUpdate` 要三个出参 (key/x/y), 少传写野指针崩。
* 跳板返回地址回填前反查二进制, 与注释互证。
* `0x4F42F0` 是本 DLL prepare 钩点: Poll 里禁调 Mark。
* `IsPlausiblePtr` 只认 `0x10000..0x7FF00000` (代码地址可用)。
