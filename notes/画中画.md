# 画中画 (PiP) — 第二摄像机小窗

在主视图之外显示战场另一区域。总开关 `[PiP] Enable`，运行时由侧栏顶部按钮开关，
默认关。只写渲染面和本地摄像机状态，不改模拟状态，联机安全。

## 原理

`TacticalClass::Render` (0x6D3D10) 是纯渲染函数：只读全局摄像机状态与目标面，
遍历 `TechnoClass::Array` 按视野绘制。临时摆一套摄像机状态和离屏面/Z 缓冲，
按引擎趟序调用即可渲染第二区域。

- mode 0=准备，1=地形，2=覆盖层+物件，3=全部；1/3 走同一分支。
- flag=1 强制整幅重画，绕过脏区增量早退。
- 引擎每帧依次调 mode 0/1/2；只调 mode=3 时脏区为空，地形趟不画。
- 渲染前补 `[0xB0E63C]=1`，mode 0 会消费该标志。
- 脏区表 (0xB0CE7C/0xB0CE88) 只由 `RegisterDirtyArea` 推进，Render 仅在项数>0
  时删末项；渲染前项数清 0，结束后还原即可。

离屏渲染期间 `PiP_InRender` 让本工程其余渲染钩子空转，重点包括
`SB_ShroudGuard`、`BlitGuardC`、`PowerDrawBoth`、`RenderEntrySwap` 与文本/UI 钩。
其中 `PowerDrawBoth` 会重建并释放 ZBuffer/ABuffer，不能让它按主视图状态运行。

## 渲染与贴窗

- 离屏尺寸 `RW = 显示宽 * ScaleNum`，显示尺寸默认 288x192，Scale 为 1 或 2。
- 依次渲染到 `g_Comp` (mode 0/1/2)，`g_Map` 暂存地形，Z/ABuffer 自建。
- 目标固定：开窗时取主相机中心，之后只由小地图点击或窗内右键拖动改写。
- 开窗后强制补渲 4 帧，避免首帧地形/缓存未就绪导致空白。
- 贴窗在缩放呈现之后进行，否则小窗会被一起缩放。
- 贴前校验源/目标行距与窗口边界；目标必须是 `GtGameW/H` 对应的窗口面。
- 离屏渲染期间跳过引擎框选带绘制（`0x6DA180`，`PiP_BandGate`）：Band 存的是
  主视口局部坐标，第二摄像机照画会贴出与内容错位的幽灵框。
- 目标行偏移按字节算：`(unsigned short*)((unsigned char*)db + y*dp) + x`。
  `dp` 是字节行距，直接按 `unsigned short*` 加会隔行并越界。
- 按 `Interval` 节流第二摄像机渲染，但贴窗每帧都做；拖动时每帧重渲。
- 仅支持 16bpp。

## 状态保存/还原

TacticalPos (+0xB0/B4)、LastTacticalPos (+0xB8/BC)、cur/tg/prx
(+0xD64/D68、+0xD6C/D70、+0xD74/D78)、+0xD7C/0xD7D、
SelectableCount (+0xDB0) 及表 (0xB0CEC8, 12B/项)、
VisibleCellCount (+0xE0) 及表 (+0xE4, 4B/项)、ViewBounds (0x886FA0)、
视口缓存 (0xB0CE28/2C/30/34)、面 (0x88731C/8872FC/887314)、
缓冲 (0x887644/87E8A4)、脏区项数 (0xB0CE88)、整幅重画标志 (0xB0E63C)。

## 坐标与定位

- `+0xD64/D68` (cur) 与 `+0xD74/D78` (tg) 是屏幕坐标，不是世界坐标。
- 世界坐标换算：`x = 30*(X-Y)/256`，`y = 15*(X+Y)/256 - ZToScreen(Z)`；
  `ZToScreen` 为 0x6D20E0。
- 格坐标换算：`x = 30*(gx-gy)`，`y = 15*(gx+gy)+15 - ZToScreen(格高度)`。
- 防出界复用缩放档的 `SB_MapPx`：把小窗视口整个塞进地图矩形，视口更大时钉正中。
- 小地图原始格钩 0x653D92 取钳制前的格，避免主视野边距限制小窗。
- 程序化相机跳转钩 0x6D6070：聚焦时把目标钉给小窗，主相机退回原位。
- 自动跟随读取 `MsgText_LatestRadar`，只在新事件到来时改目标。

## 小窗跟随 (F)

引擎自带的跟随有个硬限制：**它挂在选中集上**。换选择、取消选中、下别的令都会走
`DisplayClass` 的 Deselect 路径把 `FollowObject` 清掉，主窗口当场停下。小窗跟随是
独立的一套状态，不跟选中集走：定下目标之后换选择、取消选中、下别的令都不影响它，
只有用户明确表示"我要看别处"的动作才取消。这是小窗跟随存在的理由。

### 引擎侧链路 (实测)

| 环节 | 位置 |
|---|---|
| F 键绑定 | `KeyboardMD.ini` 的 `Follow=70` |
| 命令对象 | `CommandClass` 虚表 `0x7EBDC4`（注册点 `0x53224B`） |
| 执行体 | `0x537A10`（`a1 c8 ec a8 00` = `mov eax,[0xA8ECC8]`，5 字节） |
| 跟随状态 | `DisplayClass`(对象本身 `0x87F7E8`) `+0x119C` bool / `+0x11A0` ObjectClass* |
| setter / getter | `0x4AEB30`（`ret 4`）/ `0x4AEB10` |
| 每帧推进 | `0x55B6B3`：取 `obj+0x9C`（`ObjectClass::Location`）调 `0x6D6070` |
| 取消 | 再按 F（`0x537A3C`）/ Deselect（`0x5F44A0`，比对点 `0x5F4503`）/ 镜头跳转 `0x731826` |

`0x537A10` 就三行：没选中 → 关跟随；已跟随 → 关跟随；否则跟随 `CurrentObjects[0]`。
跟随是每帧把相机中心钉到对象 `Location`，无平滑、无插值。

### 实现

- 钩 `0x537A10`（入口 5 字节，`MOExperience_FollowEntry`），回调 `PiP_FollowCommand`。
  原函数收尾是 `ret 4`（`0x537A39` 的 `c2 04 00`），吞掉时同样 `ret 4`。
- 判定：`g_FolOn` → F 是关（不论焦点）；否则只有 `g_Show && g_Focus` 才接管，
  取 `CurrentObjects[0]` 当目标；其余位置一律放行原版（主窗口跟随）。
- 开跟随同时清引擎 `FollowObject`（调 `0x4AEB30` 传 0），并关掉 `AutoJump`
  （两者都改小窗目标，互斥）。
- 每帧 `PiP_FollowTick`：`Location` → `PiP_Div256(30*(X-Y))` /
  `PiP_Div256(15*(X+Y)) - MsgText_ZToScreen(Z)`（与 `0x6D6070` 同式）→
  `PiP_ClampScreen` → 写 `g_PinX/g_PinY`，并强制 `due=1`（跟随不能按 `Interval` 节流）。
- 取消：再按 F / 窗内右键拖动平移 / 聚焦时的小地图点击与雷达事件点击
  （两者都走 `0x6D6070`，在 `PiP_PreRender` 的 `g_RadarSteal` 分支里清）/
  自动跟随跳新事件 / 关窗 / 目标死亡。
- 目标死亡：`PiP_FolUsable` 查指针、虚表区间、`vt+0x2C/0x48`、`IsAlive(+0x90)`、
  `InLimbo(+0x81)`，再按 `Fetch_ID` 索引反查（`OU_PtrAliveRaw`，纯读不碰对象）。
  索引自检不过时 fail-open，只留字节判据。
- 边框色：跟随时画琥珀色（`PIP_C_AMBER`），优先于聚焦的绿框，用来提示状态。
- 只读 `Location`、只写本地相机与 `FollowObject`，不发事件、不改模拟，联机安全。

## 交互

- 侧栏按钮：`[PiP] ButtonPos` 按盟军/苏联/厄普西隆/焚风给 X,Y，取
  `btn_small_window.pcx` 对应阵营格画进侧栏面，随条带上屏 (同底部电量)，
  鼠标悬停时提亮。点击开关小窗，开窗落在右上角，可拖动。
- 窗内右上角按钮：移动、自动跟随、操作。
- F 键：聚焦时开/关小窗跟随（见上节）。
- 聚焦：左键按下沿落点在小窗内；点小地图保持聚焦，点其它位置帧末失焦。
- 右键：窗内按住拖动平移小窗视野，使用游戏的 8px 阈值、8 方向量化和距离速度模型；
  拖动期间 `PiP_PreRender` 钉住主相机，主视图不动。
- 操作模式：左键按下/悬停/松开都重映射到小窗视口坐标，再调原
  `ProcessClickCoords`；右键放行。
- 重映射时同时装入小窗渲染产生的可选物件表，结束后恢复主表。
- 小窗表是上一帧快照，对象可能已销毁。`ProcessClickCoords` 会直接调用
  `[obj->vtable+0x88]`，装入前必须过滤对象、vtable 和关键槽，失效项丢弃。
- 窗内左键按下钩跳过 `LeftDownPosition` 记录，避免拖框按主视图坐标误选。
- 操作模式左键拖动 = 框选：`PiP_PollMouse` 记物理起点/当前点并画实线框；
  松开那一下由 `PiP_LeftUpGate`（`0x4AB9B0`）整段跳过 `LeftMouseButtonUp`
  （防在松手点再下一次令；引擎松开路径不看 `ProcessClickCoords` 返回值，吞不掉），
  帧末把矩形换成小窗视口坐标，临时装入小窗相机与可选物件表后调引擎
  `TacticalClass::MakeSelection`（`0x6D9FF0`，过滤回调 `0x4AC2B0`），
  与原版框选同一条标准路径。几何不过阈值（`PIP_SEL_DRAG` 4px）按单击处理。
