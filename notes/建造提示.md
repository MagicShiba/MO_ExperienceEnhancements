# 建造提示 (耗时/耗电)

代码 `src/gui/ToolTip.cpp`。ini `[Features] ToolTips`。钩子见 `dist/MOExperience.dll.inj`。

## 1. 钩子与职责

| 地址 | 导出名 | 作用 |
|---|---|---|
| `0x6A93D9` | `ToolTip_Extend` | 建造图标提示退出点 (`mov eax,0xB07BC4`)，换自有缓冲，追加耗时/耗电第三行 |
| `0x478FDC` | `ToolTip_Clamp` | `CCToolTip::Draw2` 的 FillRect 点，盒子出视图就整体平移回来 |
| `0x4346C0` | `ToolTip_AdvFix` | 字宽查表，PUA 图标码回 0 避免越界宽度 |

`ToolTip_Extend` 成功时把 EAX 指向自有缓冲并跳 `0x6A93DE`；开关关/类型非法/求值失败返回 0，跑原指令。

## 2. `ToolTips=0` 的完整语义

`ToolTips=0` 时本模块对提示完全惰性，三个钩子都跑原指令：

- `ToolTip_Extend` 返回 0 → 原版两行 (名字 + 价格，`$` 不换图标)；
- `ToolTip_Clamp` 第一句返回，不记侧栏避让、不平移盒子；
- `ToolTip_AdvFix` 返回 0 (原版文本无 PUA 码)。

唯一例外是 Phobos 副本对齐 (§3)：那份副本由 Phobos 绘制，不属于本模块的提示功能，开关不影响它。

## 3. Phobos 在场时的两个提示框

引擎每帧调两次 `CCToolTip::Draw`：

```
0x4F4570  push 0  → 主视图路径
0x6A708D  push 1  → 侧栏路径
```

Phobos 把 `Draw` (`0x478E10`) 整个替换：`Draw(0)` 时置 `SlaveDraw`，经 `0x478E4A` 钩子强制改画到 Composite；`Draw(1)` 正常画到 Sidebar。cameo 提示因此被画两份。

`IsCameo` 在 Phobos 的 `0x6A9316` 钩子里无条件置位 (在 `IsEnabled` 判断之前)，所以 `[ToolTips] ExtendedToolTips=no` 也去不掉第二份。

两份位置不同：Sidebar 那份在屏幕上的位置是 `屏宽 - 盒宽` (右沿贴屏右)；Composite 副本被 Phobos 的 `0x478F52` 钩推到 `屏宽 + 侧栏宽 - 盒宽`，比侧栏那份右移一个侧栏宽。盒宽 ≤ 侧栏宽时副本整块在屏外，看不见；盒宽 > 侧栏宽时在屏幕右沿露出一条 (实测 180 → 露 12px)，像第二个框。

MOE 在 `ToolTip_Clamp` 开头把「越过 Composite 右界」的副本对回 `屏宽 - 盒宽`，与侧栏那份重合；只在越界时触发，正常提示不动，且与 `ToolTips` 开关无关。

MOE 自身的越界平移在 Phobos 在场时停手：否则会把已对齐的副本从侧栏区拽进视图，反而变成并排两个框。

## 4. 与 Phobos 文本的关系

`uimd.ini` 的 `[ToolTips] ExtendedToolTips=yes` 时，Phobos 在 `0x6A9316` 生成文本并跳到 `0x6A93DE`，跳过 MOE 的 `0x6A93D9`。此时耗时/耗电由 Phobos 提供，MOE 只剩副本对齐和 (Phobos 不在时的) 越界平移。

## 5. 日志

| 行 | 含义 |
|---|---|
| `tooltip: power+time ON` | 启动读到 `ToolTips=1`，或 ESC 页打开 |
| `tooltip: power+time OFF` | 启动读到 0，或 ESC 页关闭 |

ESC 设置页切换会把值写回 `MOExperience.ini`，所以日志里的 ON→OFF 不一定是启动读取失败。
