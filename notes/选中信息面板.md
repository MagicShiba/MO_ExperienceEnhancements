# 左下角选中信息面板

代码: `src/gui/UnitPanel.cpp`。入口: 无（常驻），由 prepare 钩轮询 + 消息帧钩绘制。

## 版面

- 九宫格外框 `border_mental_n9_B.pcx`（36×36，分割线 上8/下6/左右7，边距取同值
  所以框带 1:1 不重采样）。框只包格子，**格数按内容定**：单选 2 格（2×1）、4 架
  2×2、9 个以上才 3×3，格间留 1px 缝，不留空槽。
- 框外左侧一列按钮，自下而上：折叠 / 操作模式 / 收藏 1..4（收藏按钮按用过的槽
  逐个露出，见 `notes/收藏单位.md`）。三组按钮各受一个开关管（`BtnFold` /
  `BtnWasd` / `BtnFav`，ESC 设置页「单位面板 → 左侧按钮」一行四段：关闭 = 三组
  全关）。**关掉一组就不占位**——`s_BtnId[位置] = 逻辑按钮`，绘制/命中/点击一律过
  这张表；三组全关时 `s_HasBtnCol = 0`，面板不再给按钮留宽度、直接贴左下角。
  关掉折叠键会强制展开（否则永远点不开），关掉 WASD 键会同时收掉键盘移动模式
  （否则键还在被吞却没有任何指示）。整块贴视口左下角，`Margin` 可整体挪。
  锚点基准 = 满视图区 A（`FM_GetViewRects`），1x 时与引擎视口相同；不能拿
  ViewBounds 缓存（0xB0CE28）当界线——缩放档它是 A×scale，UI 会跟着缩放跑
  （同 notes/地图缩放.md §6 那批）。
- 没选中任何东西时**只留按钮列**，不画那块黑板。
- 外框分两遍贴：先满贴当内底，画完格子再只补框带（否则中心的不透明近黑会盖掉
  cameo）。

## 四种版式

| 选中 | 排法 |
|---|---|
| 1 个 | 格0 = 图标（等级/弹药），格1 = 血量/经验，格2 起 = 载员 |
| 同型多个 | 每单位一格，按弹药从少到多排（空弹优先看见） |
| 混型 ≤ 9 | 全展开，同类型相邻 |
| 混型 > 9 | 按类型分组，右上角画数量 |

载员超过 7 个（`UP_CELLN - 2`）翻页，前两格每页固定，末页末格是「更多」；
滚轮在面板上翻页，页码点画在下边框带上。

载员有两种存储，互斥：驻军走 `BuildingClass::Occupants`（Items 0x688 / Count 0x694），
吸收型建筑（`InfantryAbsorb`/`UnitAbsorb`，生物反应炉 YAPOWR、光棱塔 NAPRIS）走
`TechnoClass` 载员链（0x114/0x118），与载具同一套。建筑先读 Occupants，为空再读链。
两种都能点着单卸（见 `notes/单个载员下车.md`）。

**可见性**：只看容器（车/楼）的归属，每次重建判一次——`FN_HOUSE_ISALLIED`（0x4F9A50）
判本家对容器 `Owner`，敌人的整份舱单一格都不列，本家与盟友照列。选中的对象可能本来
就是别人的（点选敌人单位），这个位置不拦等于白送一份敌方舱单。
**载员本身不判**：心控来的敌车 `Owner` 已改成我方（原主存在 `CaptureManager` 节点里），
车里装着的敌方载员照列、照放——与引擎"能放出敌方单位"一致。
观战者不受限（不参与对局）——注意观战判据 `Observer_LocalIsSpectator()` 有误判风险
（见 `notes/观战.md`），误判会让这一整条过滤失效。

## 按钮图标

手绘（不走 GdiText，18px 里放不下字形）：

- 折叠键：`Up_Tri` 6x11 实心三角。**展开时指左、折叠时指右**（`right` 参数 =
  `s_Collapsed`）。三角每行宽 `len = 6-|j-5|`，左指时起点 `half`、右指时起点 0，
  两种朝向靠"填哪一侧"区分（按 `len-1-i` 写两边会画出同一块）。
- 操作模式键：`Up_Exch`，11x12 的「⇋」（上排左箭头 + 下排右箭头，2px 笔画；
  1px 压在地图上就糊了）。
- 收藏槽：`Up_Star` 11x11 五角星，空槽是同色暗星。

## 角标

`full` = 非敌方，或本机是观战者（`Up_DrawIconCell` / `Up_DrawInfoCell` 各算一次，
观战判据 `Up_LocalSpectator()` 按帧缓存 `Observer_LocalIsSpectator()`）。
`full=0` 只发生在非观战对局里选中敌方单位：只给图标 + 血条 + 血量，别的全不列。
观战不参与对局，地图上本来就画着敌方的等级与余弹，面板跟上即可。

- **等级**：图标左上，一级金色 ︿、二级金色星星，与画面上的单位标记一致。
- **血条换色**：只看当前血量比例，**不分敌我**。与引擎同口径，阈值 = MO 的 rules
  `[General] ConditionYellow=67%` / `ConditionRed=35%`（>67 绿 / >35 黄 / 其余红），
  常量 `UP_HP_YELLOW_PC` / `UP_HP_RED_PC` 写在 UnitPanel.cpp 顶部；rules 改了要同步。
- **弹药**：cameo 底部烧死了单位名（约 12px），所以弹药格抬到名字上方、
  从左下往右铺；一排几个看 rules 的 `PipWrap=`（缺省 6），格数看 `Ammo=`。
  满的发亮黄，空的是暗块。
- **经验条**：等级内进度（精英满格）。
- **数量**（组显示）：右上角，字体/字号取资金（顶栏资源数字）那套。

## 图标来源

`art.ini` 的 `CameoPCX=`（Ares 键）指向 .pcx 时走 `PCX::Instance` + 最近邻缩到
60×48；否则回退 `CC_Draw_Shape` + `CAMEO_PAL` 现渲（MO 的单位多半是前者，SHP 那条
路画出来是紫球）。**装载/渲染都必须放在 UP_Poll**：会动引擎面池，绘制帧只读缓存。

类型指针只当键用，不解引用（取图标/血量/弹药前都过 `IsPlausiblePtr`）。

## 详情行（右键折叠键）

右键折叠键在「普通 / 详情」两态间切（`s_Detail`，纯运行期状态、不落盘；折叠态
`Collapsed` 才是 ini 项）。详情态**且单选**时面板底部多一行图标（`UP_DET_H` = 17px：
2px 间距 + 15），面板整体往上长、底边仍钉在视口底。8 个图标**排成一行**、中间不留缝：
块宽 120px，格子区（2 格版式）内宽 121px，正好放得下；排成两排只会白占 15px 高度。

图标表 `icon_unit_up_type.pcx`（内嵌资源 `ICONRES_UNITUP_TYPE`）本身是 **60×32、
表内 4 列 × 2 排 15×15（第二排起始 y=16）**，但屏幕上是把两排并成一行画的
（`UP_SH_COLS` / `UP_SH_ROWY` 只管取图，与屏幕排布无关）：

| 屏幕位次 | 含义 | 判据 |
|---|---|---|
| 1 | 火力（升级） | `ABIL_FIREPOWER` |
| 2 | 生命（升级） | `ABIL_STRONGER` |
| 3 | 速度（升级） | `ABIL_FASTER` |
| 4 | 自愈（升级） | `ABIL_SELFHEAL` |
| 5 | 火力（箱子） | `FirepowerMultiplier` 0x160 > 1 |
| 6 | 护甲（箱子） | `ArmorMultiplier` 0x158 > 1 |
| 7 | 速度（箱子） | `FootClass::SpeedMultiplier` 0x580 > 1 |
| 8 | 隐形（箱子） | `Cloakable` 0x3D2 且类型本身 `Cloakable=` 不是 yes |

- **升级那 4 个 = `TechnoClass::HasAbility`（0x70D0D0）**，只读，联机可用；它自己
  按当前等级（Veterancy 0x150 → 老兵/精英）去查 `type+0x29C` / `type+0x2AE` 的位图。
- **箱子那 4 个 = 单位身上的字段**（箱子拾取分支就是写这几处：0x482E71 /
  0x483240 / 0x483060 / 0x48294F）。
- 敌人（非观战）看不到这一行，与「两格只给图标+血量」同一口径（`Up_InfoFull`：
  本家 + 盟友能看，敌方只有观战能看）。多选时面板上放不下这行，同一张图改由
  悬停提示框画（见下节）。
- 画法：表自带透明色（PCX 左上角那个像素，引擎装载时记成 `PcxImage.key`），逐像素
  `v == key` 就跳过；**不再按亮度猜背景**。拥有的原色贴，没有的按亮度乘 45% 压成暗灰。

## 悬停提示框

鼠标落在**面板上**（`Up_HitPanel`；按钮列与框外空白不算）就出提示框，目标跟着鼠标：

- 压在有单位的格子上 → **那一格**的单位（多选里的一格、车下载员都算）；
- 压在面板主体但没压到有单位的格子 → 单选的那个（`s_List[0]`）。

```
装甲步兵车                    ← 类型 UIName（格子下那行名字受 cameo 尺寸限制会被截，有的单位没图标）
────────────                  ← 名字下一条半透明白分隔线
[8 个能力图标]                ← 面板上没有那行常驻图标时才画（多选 / 载员 / 详情态没开）
生命  275/330   +40% (462)    ← 左列原值（当前/本型满血，满血时不写 "/330"），右列加成
速度  7.5       +25% (9.4)    ← 左列 rules Speed，右列乘过倍率后的实际速度；建筑没有这一行
护甲  轻甲                    ← 类型节 `Armor=` 沿 [ArmorTypes] 解析到基础档
自愈  3/秒                    ← 自带/老兵(Ares 口径) + 占了科技医院·机械厂(Phobos 光环，按层数)
```

- 三列：标签 | 原值 | 加成。列宽按 `RenderLine` 实测（`UP_TIP_COL_GAP`=6），右列所有行
  都从 `+` 起排，所以两行的加号**垂直对齐**；右列 = `+40% (175)`，括号里是加成后的
  实际/折算值（生命 = 折算满血 `满血 × 倍率`，速度 = `原速度 × 倍率`）。
- **没有数据的那一行整行不画**：不写 `—`、不占位；没有加成时右列留空（既不写 `+xx%`
  也不写括号）。
- **可见性 = 本家 + 盟友**（`HouseClass::IsAlliedWith` **0x4F9A50**，同盟含自己）；
  敌方只有观战者能看（观战不参与对局，地图上本来就画着它的等级和余弹）。与「两格」
  同一条判据 `Up_InfoFull`，所以"能不能看盟友/敌人"全项目只有这一处口径。
- **行距按墨迹排**（`Up_InkMetrics` 量一次 `国Gg`）：行高 = 墨迹高 + 3，墨迹在行高里
  垂直居中（`y = 行顶 + (行高 - 墨迹高)/2 - inkTop`）。字体 cell 含 ~6px leading，按它
  排行会空出一大块 —— 与 `notes/存档截图.md` 里那个列表同一个做法。
- 字号/字体**跟随 `[VecText]`**（`VecText_FontPx/FontFace/Bold`），与侧栏那份悬停提示
  一致；单独占 GDI 槽 `UP_TIP_SLOT`=14（`GDI_SLOTS` 因此从 14 提到 15），不与面板
  正文（`[UnitPanel] FontPx`）互相拆了重建。
- 样式：半透明黑底 + 1px `A5D3FF` 边 + 白字；名字下一条半透明白分隔线（`UP_TIP_NAME_GAP`=3）。
- **位置固定不跟鼠标**：贴面板右侧（放不下翻到左侧），底边与面板底对齐，宽高按
  内容自适应。逐像素跟随要整块重画，位置也会晃。
- 名字取 `type+0x60`（`OFF_TYPE_UINAME`）：引擎装载时已把 UIName 的 CSF 键解析成
  `wchar_t*` 存在那儿（0x410960），**不要去调 CSF 函数**（它用 ecx/edx + 两个栈参）。
- 数值口径：
  - 生命：原值 = `type+0xA0`（满血）与 `Health`；加成后 = `满血 × (HasAbility(STRONGER) ? VeteranArmor : 1) × 对象 ArmorMultiplier`（两者都是"少掉血"，等效加血）
  - 速度：原值 = rules 的 `Speed`；加成后 = `原值 × (HasAbility(FASTER) ? VeteranSpeed : 1) × FootClass SpeedMultiplier`
    （建筑不算，整行不画；节名 = 类型 ID，从 `INI_Rules` 现读）
  - 护甲 = 类型节 `Armor=` 的别名沿 `[ArmorTypes]` 的 `别名=基础名` 走到底（MO 里
    `flak_t1=flak`、`arch=gharial=heavy`），再映射成 无甲/布甲/钢板/轻甲/中甲/重甲/
    木甲/钢甲/混凝土/特殊1/特殊2；走不通（没写/链断）就整行不画。
    MO 的 1811 个单位节里 1758 个能解析到基础档，剩下的都是 `Armor=addon/special/magnet`
    这类不可选中的残留节。
  - **自愈**：三条来源，只算"单位自己"的恢复，不掺外部维修：
    1. **Ares 口径**（一个开关两个入口）：类型自带 `SelfHealing=`（类型字节 `+0xD14`）、
       老兵/精英带的 `ABIL_SELFHEAL` 能力。数值 = 每 `max((int)(Rate×900),1)` 帧回
       `SelfHealing.Amount` 点；`Rate` 没写用 `[General] RepairRate`（0.03 → 27 帧），
       `Amount` 没写算 1 点 → 约 **0.55 HP/秒**。原版引擎每步只 +1 HP 且没有 Amount，
       Ares 把 `ShouldSelfHealOneStep`（0x6FA743）整个换掉了。
    2. **Phobos 的 GainSelfHeal 光环**：科技医院 `[CATHOSP]` / `[CAFHOSP]`
       (`InfantryGainSelfHeal=1`)、科技机械厂 `[CAMACH]` (`UnitsGainSelfHeal=1`)，
       **不需要进楼、不需要停留，占领即对己方全体生效**。数值 = 每
       `SelfHealInfantry/UnitFrames` 帧回 `Amount × 层数` 点 → 每层步兵
       **3 HP/秒**、载具 **1.5 HP/秒**。口径照 `TechnoExt::ApplyGainedSelfHeal`：
       步兵走步兵参数；载具看 `type+0xD97`（`Organic`）为真则按步兵参数；
       **飞机和建筑**默认 `NoHeal`（WhatAmI 不在那两类里，MO 也没写 `SelfHealGainType=`）。
    两条路**相加**（Ares 换虚函数、Phobos 是独立的 Update 钩子，互不知情）。
    1 游戏秒 = 15 帧，回血有间隔也按折算后的每秒值显示；都没有 → 这一行不画。
  - **层数直接从 House 读，不扫建筑表**：引擎在建筑放下时就把类型的值累加进
    `House+0x164`（InfantrySelfHeal）/ `+0x168`（UnitsSelfHeal），拆楼时减回。读一个
    int 就够，**不用遍历 `BuildingClass::Array`**，也不会漏掉建在迷雾里的楼；Phobos 判
    "有没有这个光环"读的也是这两处，所以面板与引擎/Phobos 永远一致。
  - ⚠ **`RepairRate`(+0x16E0) + `RepairStep` 不能拿来算单位**：那是建筑自己被
    工程师/修理车修的步进（0x450826 帧号门控 + `+0x6E8` 分支）。停靠单位吃的是
    `IRepairStep`/`URepairRate`，按现口径**不显示**（外部维修不算自身自愈）。
- rules 数值一律从 `INI_Rules` 现读（地图内嵌 ini 能改写 `[General]`/`[Powerups]`）：
  `[General] VeteranCombat/Armor/Speed`、`SelfHealInfantry/UnitFrames+Amount`、
  `RepairRate`（Ares 的 `SelfHealing.Rate` 缺省值），`[Powerups] Firepower/Armor/Speed`
  的第 4 段。**节名必须是字符串字面量或类型 ID**，否则会把 INIClass 的按指针
  节缓存顶掉（见 `EngineAddr.h` 的 `ADDR_INI_ART` 注释）。

### 压掉引擎自己的悬停提示

面板压在视口上，引擎仍认为鼠标在地图上，会照常画出"未探索的区域"/地形名，正好盖在
我们的提示框上。所以钩 `CCToolTip::Draw2` 入口 **0x478E30（7B）**：鼠标落在面板
（`UP_HitPanel`，含折叠态那颗键）上时整个函数不画 —— 跳到 0x478E0C 那条裸 `ret 4`，
**不能**跳它自己的尾段（那里会 pop 尚未压入的寄存器）。抢的 7 字节是
`mov edx,[esp+4]` + `sub esp,0x2c` 两条完整指令、无 rel，放行时原样重放。
里面 0x478FDC 那个 FillRect 点已被 `ToolTip_Clamp` 占着，两者不重叠。

## 点击

面板压在视口上，引擎会把落点当地图点击（取消选择 / 下令），所以在
`DisplayClass::ProcessClickCoords` 挂门（Syringe `0x692361`）：落点在面板内就跳到
`0x6925FC`（原函数"未处理"出口）吞掉。门里只记坐标，真正的选中动作放到下一次
`UP_Poll` —— 那一帧已经不在引擎点击链路里，调 `UnselectAll` / `Select` 才安全。

| 落点 | 动作 |
|---|---|
| 折叠键（左键） | 折叠/展开（折叠时强制关掉键盘移动，否则吞键却没有指示） |
| 折叠键（右键） | 切「普通 / 详情」两态（见上「详情行」） |
| 操作模式键（图标是 ⇋） | 开关键盘移动，见 `notes/键盘移动.md` |
| 收藏槽 | 见 `notes/收藏单位.md`（空槽单击收藏 / 已用槽单击跳转 / Ctrl 覆盖 / 长按清空） |
| 单选版式格 0/1 | Z 按住 = 给全部载员规划；否则不动（容器本身不靠面板下令） |
| 载员格 | 单个下车；按住 Z = 给该载员规划；按 shift = 挂多选名单（都不看 Z） |
| 其它格 | 选中那个单位（组则整组） |

## 日志

全部 `up: ` 前缀，只留低频行：

- 启动一行 `up: enable=… margin=… px=… fold=… btn=… face=…`；设置页改开关时各一行。
- `up: nmu id=… v=… ini=…`：每个 rules 时代第一条必记（`ini=0` 或读不出值一眼可见），
  之后只记真值。
- `up: rules vet=…/…/… crate=…/…/… heal=…/…/…/… rr=…`：rules 数值缓存重建时一行。
- `up: det sheet ok` / `bad size`（尺寸不对 1s 后重试）、`up: border n9`（只记一次）、
  `up: geom p=… cells=… pages=…`（版式只记一次）。
- `up: heal ares=… gain=… milli=…`：自愈数值变化时一行（面板详情行与提示框共用这一个
  打点，所以悬停到别的单位也可能打），用来核对层数有没有进 House。
- 状态翻转：`up: collapsed/expanded`、`up: keymove on/off`、`up: detail on/off`、
  `up: enable on/off`。

**不要按选中集打格子清单**（每换一次选中就刷一屏）。
