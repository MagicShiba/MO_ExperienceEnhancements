# 左下角选中信息面板

代码: `src/gui/UnitPanel.cpp`。入口: 无（常驻），由 prepare 钩轮询 + 消息帧钩绘制。

## 版面

- 九宫格外框 `border_mental_n9_B.pcx`（36×36，分割线 上8/下6/左右7，边距取同值
  所以框带 1:1 不重采样）。框只包格子，**格数按内容定**：单选 2 格（2×1）、4 架
  2×2、9 个以上才 3×3，格间留 1px 缝，不留空槽。
- 框外左侧一列按钮，自下而上：折叠 / 操作模式 / 收藏 1..4（收藏按钮按用过的槽
  逐个露出，见 `notes/收藏单位.md`）。整块贴视口左下角，`Margin` 可整体挪。
  锚点基准 = 满视图区 A（`FM_GetViewRects`），1x 时与引擎视口相同；不能拿
  ViewBounds 缓存（0xB0CE28）当界线——缩放档它是 A×scale，UI 会跟着缩放跑
  （同 notes/地图缩放.md §6 那批）。
- 没选中任何东西时**只留按钮列**，不画那块黑板。
- 外框分两遍贴：先满贴当内底，画完格子再只补框带（否则中心的不透明近黑会盖掉
  cameo）。

## 四种版式

| 选中 | 排法 |
|---|---|
| 1 个 | 格0 = 图标（等级/弹药），格1 = 血量/经验，格2 起 = 载员 |
| 同型多个 | 每单位一格，按弹药从少到多排（空弹优先看见） |
| 混型 ≤ 9 | 全展开，同类型相邻 |
| 混型 > 9 | 按类型分组，右上角画数量 |

载员超过 7 个（`UP_CELLN - 2`）翻页，前两格每页固定，末页末格是「更多」；
滚轮在面板上翻页，页码点画在下边框带上。

## 角标

- **等级**（仅我方）：图标左上，一级金色 ︿、二级金色星星。
- **弹药**（仅我方）：cameo 底部烧死了单位名（约 12px），所以弹药格抬到名字上方、
  从左下往右铺；一排几个看 rules 的 `PipWrap=`（缺省 6），格数看 `Ammo=`。
  满的发亮黄，空的是暗块。
- **数量**（组显示）：右上角，字体/字号取资金（顶栏资源数字）那套。

## 图标来源

`art.ini` 的 `CameoPCX=`（Ares 键）指向 .pcx 时走 `PCX::Instance` + 最近邻缩到
60×48；否则回退 `CC_Draw_Shape` + `CAMEO_PAL` 现渲（MO 的单位多半是前者，SHP 那条
路画出来是紫球）。**装载/渲染都必须放在 UP_Poll**：会动引擎面池，绘制帧只读缓存。

类型指针只当键用，不解引用（取图标/血量/弹药前都过 `IsPlausiblePtr`）。

## 点击

面板压在视口上，引擎会把落点当地图点击（取消选择 / 下令），所以在
`DisplayClass::ProcessClickCoords` 挂门（Syringe `0x692361`）：落点在面板内就跳到
`0x6925FC`（原函数"未处理"出口）吞掉。门里只记坐标，真正的选中动作放到下一次
`UP_Poll` —— 那一帧已经不在引擎点击链路里，调 `UnselectAll` / `Select` 才安全。

| 落点 | 动作 |
|---|---|
| 折叠键 | 折叠/展开（折叠时强制关掉键盘移动，否则吞键却没有指示） |
| 操作模式键 | 开关键盘移动，见 `notes/键盘移动.md` |
| 收藏槽 | 见 `notes/收藏单位.md`（Ctrl 收藏 / 单击跳转 / 长按清空） |
| 单选版式格 0/1 | Z 按住 = 给全部载员规划；否则不动（容器本身不靠面板下令） |
| 载员格 | 单个下车；按住 Z = 给该载员规划；按 shift = 挂多选名单（都不看 Z） |
| 其它格 | 选中那个单位（组则整组） |
