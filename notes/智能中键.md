# 智能中键

背景：README“智能中键计划”——中键拖动下单（巡逻圈/散开/阵型/砍树/模糊选目标），
快捷键可改到其它键位。铁律（AGENTS.md）：禁本地直调改模拟的引擎函数，
所有模拟变更走标准事件（Mega/Connect/Commit）广播；只读查询 + 渲染面绘制安全。

触发互斥（松开瞬间归属）：裸中键=智能下令（点按自适应/划线散开），
组合中键=范围智能（默认 Shift+Middle，可单键），
Z+中键=巡逻（范围智能认领时让路），Ctrl+Z+中键=砍树，
Ctrl+中键无Z=模糊，Shift+P=心控收敛。
键位正名：红警2 左键选中+下令（移动/攻击/进驻），右键取消/拖拽平移镜头，
中键原版无功能（手册与 StrategyWiki 双确认）。

## 快速砍树，模糊攻击

- 新建 OrderUtil（下单模块共享：PatrolCircle/SmartOrder/TreeChop/FuzzyAttack）：
  `OU_WhatAmI/OU_Enqueue/OU_CellValid/OU_MouseCell(Px)/OU_PtrAlive(Raw)`；
  地址全只读：OutList `0xA802C8/0xA802D0/0xA802D4/0xA83A54`（SIZE=111/CAP=0x80），
  Frame `0xA8ED84`，选中 `0xA8ECBC/0xA8ECC8`，本家 `0xA83D4C+0x30`，
  Display `0x87F7E8`，Fetch_ID `0xB0E840/0xB0E844` 二分存活校验（fail-open）。
  事件编码：`Mega 0x04 ctor 0x4C6860`，`Connect 0x2A 0x4C6780`，
  `Commit 0x2B 0x4C66C0空载荷`；Misson Move=2 Attack=1（禁 Action=5）。
- PatrolCircle 重写（640行）：改原生两阶段——逐点 Mega（`Follow=Dst`）+ 全员 Connect-only 合环；
  16 节点弧长重采样；框选 skew 改固定矩阵。
- SmartOrder 瘦身（-261行走 OrderUtil）：恒飞 `Aircraft==2`，
  地面 `MZ@1460==9` 主、`ST@1596==4` 兜底；64 节点散开。
- 砍树（Ctrl+Z+中键，选中地面单位强制攻击树木）：
  `CellClass::GetTerrain 0x47C550` 直取，`TerrainType 0xA8E318` 自校准，
  ID 以 `TREE / TIBTRE` 开头；`Range 2~16`（dist 默认 6），
  按单位全覆盖分配（`unit u -> tree[u % nt]`，树少时多单位集火同一棵，`IsPlanningEvent=1` 排队）；
  画框走引擎 `CoordsToClient 0x6D2140` 投影格线角点（逐角取高），与扫描同格；
  中键不平移镜头（平移是右键），Ctrl 按住时巡逻圈让路。
- 新建 FuzzyAttack（Ctrl+中键无Z，蜘蛛类难选中目标）：
  `CellClass::FindObjectOfType 0x47C4D0` 取链头 + `NextObject+0x30` 走链
  （64步，指针+WhatAmI双守卫）；Owner 双选中单位自校准，失败放弃绝不错击；
  `SquadSize=4` 集火分组；`IsPlanningEvent=0` 直接下令。
- BuildQueue 定案，详见 notes/BuildQueue建造队列.md。
- build-fast.bat 加 TreeChop/FuzzyAttack/OrderUtil（mingw32无CRT禁memmove）。

## 中键智能下令（点按自适应/划线散开/落点转换）

- 动因：裸中键原来只发移动令（点民房不进驻），Ctrl+中键模糊只发
  攻击令（点民房摧毁）；划线/点空地落点压建筑上时走过去再转攻击。
  目标：与左键下令同自适应。
- 逆向（tools/disasm.py 实证 gamemd.exe）：
  `DecideAction 0x692610` 只读（全范围无事件构造/OutList 引用；
  thiscall ECX=Display，栈 (cell*, obj, 1)，EAX 回 Action）；
  `FootClass::Active_Click_With 0x4D74E0` 跳转表 `0x4D7D04/0x4D7CD0`：
  Move1→idx0、Enter3→idx2(Mission7 载具)、Attack5→idx4(Mission1)、
  Capture9→idx5(Mission8，步兵进驻民房原生即此，0x51E6A8 实证）、
  Repair11→idx6(Mission9)、Sabotage16→idx7(Mission17)、
  GuardArea26→idx8（民房 Mission17 否则 AreaGuard11）。
  进入类布局 Target={0,0}+Destination=目标对象（AutoLoad §11 同构）。
- 实现（联机安全：只读查询 + 标准事件；不调
  ObjectClickedAction/ClickedMission）：
  OrderUtil：`OU_MouseCellTarget`（格+点中对象）、`OU_MouseOverObject`
  （vtbl+0x74；Unit 0x73FD50/Infantry 0x51E3B0 双确认）、`OU_DecideAction`、
  `OU_GetCoords`（vtbl+0x48，0x4DDED0 内同槽取坐标实证，范围校验）。
  归属/类型自校准（FuzzyAttack/SmartOrder 同式）。
  SmartOrder：终点有对象→全局 Decide + 逐单位能力过滤
  （同任务下单/会移动跟随/分歧无操作；未知动作无操作；Repair 等不转发）；
  全局 NoMove 时退回逐单位判定；护驻军（建筑可进驻则攻击改移动）；
  空地→散开（点按螺旋配额/划线弧形）；落点转换（`AS_Queue` 内，
  地面单位落点压建筑按直接下令，空军除外，护航不转回攻击）；
  终点有对象永不散开（0=散开/1=已下单/2=无操作），移动散开跳建筑中心格。
- 避坑：`vtbl+0x1A4` / `0x4AE750` 不是下单函数；已发事件不用队列余量判断。
- 日志：仅启动行（`airspread: ON`）。
- ini 无新键（注释已改智能下令），dist 与游戏内 ini 同步；构建零警告。

## 组合中键范围智能（`src/SmartArea.cpp`，`[SmartArea]`）
- 手势：Hotkey（默认 `Shift+Middle`，主键须是 Middle，可单键如 X1）
  点按/划线，松开即执行。点按=单块，划线=沿轨迹各节点逐块环扫
  （去重，松开格点中排首，上限 64 节点）。按住显示范围框（Range 同大）
  + 规划线（SA 绿/FA 红，细线，单位→分到的目标，松手即消）。
- 决策（与裸中键同一套函数，差的是输入）：逐单位 MouseOver，
  攻击/进入/进驻/占领才下单，移动/未知跳过（不下移动令）。
  光标无令（Shift 按住时部分目标回 ToggleSelect=8，真光标被盖住；
  只读不写键态，不接管）走 fallback 规则表：
  本家目标步兵对自家载具按进入、其余跳过（绝不误击本家）；
  非本家载具/飞机/步兵对非建筑强攻（与模糊同语义，Owner 双单位自校准，
  盟友注意）；工程师（ENGINEER/S/Y/F，rulesmo 实查）对建筑按占领；
  Damage28 等敌意光标按攻击（工程师对非本家建筑转占领）；
  非工程师步兵对建筑留待命。
- 分组：进驻（Capture/Sabotage）第 0 轮按建筑轮转均分（不管 SquadSize）；
  其余每目标首轮 Squad 个，剩下的找最近可处理目标加入。
- 待命：分不到的等脏键全松后重判（脏=配置修饰/附加键真按住，
  或物理 Shift 按住；空真陷阱：ModsDown(0)/ExtraDown(空)恒真，
  无修饰单键必须看物理 Shift）；超 300 轮丢弃；框保持。
- 仲裁：须无 Ctrl（含 Ctrl+Shift+中键归模糊）；Z 不禁
  （巡逻圈见 SA 认领主动让路，Z+裸中键仍归巡逻）。
  关/坏键不认领，组合中键回落裸中键。
- 预览：快照+分配与终判同一套（发令/记线双 sink，终判松手重扫一次）；
  截断前 64 单位/前 96 目标/128 线（终判全量）；
  换格/节点数变或 400ms 刷、80ms 节流；端点存 leptons 世界坐标
  （单位中心含高度），绘制期经引擎 `CoordsToClient 0x6D2140` 投影
  （屏像素跨帧漂移，世界坐标恒准；落地端取 `GetFloorHeight 0x47B3A0`）。
- 规划线三家共用 `OrderUtil OU_Prev*`：`OU_ProjWorld/OU_CellGroundZ/
  OU_ThinLine/OU_PrevPush(Objs/Cell)/OU_PrevDraw/OU_PrevThrottle`，
  FA 红/SA 绿/SO 绿同一套细线与节流；FA/SA 旧屏像素换算与自有细线已删。
- 裸中键划线/点按绿线预览（`src/SmartOrder.cpp`）：按住时与松手同一套
  分配（`SO_Queue/SO_SmartPoint` 经 `s_SoPrevSink` 只记线不下令，
  螺旋配额与弧长重采样复用 `SO_SpiralCells/SO_SpiralAssign`），
  换格/节点数变或 400ms 刷；落点转换预览与终判同规则。
- 逆向：键查询全 exe 仅 0x53EC70 后备分支/窗口过程/点击修饰组装三处，
  DecideAction/MouseOver 零键读取；0x53EC70 唯一调用在 0x54F25B。
- 认领含主键时松开边用无主键判定；已发事件不用队列余量判断。
- 改名（AirSpread→SmartOrder，MsgFont.dll→MOExperience.dll）：
  符号/导出名/ini 节/构建脚本全套跟改；Syringe 按文件名配对加载，改名安全。
  游戏目录手动删旧 dll/inj 并改 2 个节名。

## 中键基地车展开预览+自动展开（`src/DeployPreview.cpp`，`[DeployPreview]`）

- 动因：基地车（rules `[General] BaseUnit=AMCV,SMCV,PCV,FMCV`，如 AMCV→GACNST）
  展开成大地基建筑，落点差一格就歪。物理中键按住时画黄框（落点地基外框，
  引擎投影吸格线）+ 细框（目标格=光标格），对墙对齐；松手车开过去到位自展。
- 锚点（闭环，预览=移动目标=实际落点同一套数学）：
  基点 = 光标格 +（大地基 -1,-1）；
  车移动目标 = 基点 +(1,1)（与手点同形）；落点 = TryToDeploy 公式
  （0x7393C0 反汇编 + 运行时读值双确认）。
- 认领：`DeployPreview_ClaimsMiddle`（开关+AutoDeploy 开、物理中键按住、
  无 Z/Ctrl、SmartArea 未认领、选中含可展开单位），SmartOrder 按下/按住让路。
  只看按下瞬间快照（基地车记每车实际地基 + 其它单位 + 起点格），新点按取代旧跟踪。
- 分配三路（预览与松手执行同一套，所见即所得）：
  单车起点=终点（框跟鼠标自由走）；多车点按 `DP_AssignPoint` 螺旋平铺
  （步长=各车 max(宽,高)之大者 `DP_MaxStep`，块块判交不重叠）；
  划线（轨迹弧长 ≥5 格）`DP_AssignLine` 沿手绘轨迹弧长均分
  （节点步长 2、上限 64，`DP_ArcLen/DP_ArcPos`，间距=步长与全长均分之大者，
  短线沿末段方向外延）；Shift 按住 `DP_AssignStraight` 锁横/竖轴排一排。
  混编其它单位 `DP_ScatterOthers` 按配额（步兵3/格，飞机/车辆1/格）散开，
  跳过房框实际尺寸外扩 1 格；没分到房的基地车转入散开（只走不展）。
- 下令（全程标准事件，联机安全）：移动 `MegaMission(Move)`
  排队滴发（64/轮，`DP_TryMoveHead/DP_DrainMoves`）；到位轮询
  （`DP_UnitCell` 比对）发 Deploy 事件 `0x9`（ctor 0x4C65E0，与手按 D 同形）。
  死车/换边/超时（DeployTimeout 秒，默认 45）/无处可铺则放弃。
- 绘制：认领态白轨迹线（节点格心连线 + 当前格心橡皮尾巴，
  SmartOrder 熄火时补上）+ 每车黄框 + 目标细框；未认领单框老路。
  投影唯一出口 `DP_CornerLep` → 引擎 `CoordsToClient 0x6D2140`
  （单例 0x887324），每角 Z 取其框内格 `GetFloorHeight 0x47B3A0`
  （传 `Point2D*` 单指针 + ret 4，传错栈失衡），无效格回落光标高。
  绘制三件套 `DP_PlotC/LineC/MarkC` 按颜色统一（黄房框/白轨迹）。
- 最小参照：`Unit+0x6C4`=UnitType，`UnitType+0x404`=DeploysInto，
  地基宽/高 `0x45EC90/0x45ECA0(0=不含bib)`；类型取得只解引用选中活对象
  与静态类型数组（`DP_InTypeSet` 只比指针），无扫描无字符串探测；
  无 CRT（禁 memmove/结构体赋值，逐字段搬）；地基尺寸指纹缓存
  （选中签名+500ms，大编队封顶 64）。
- 结论：手算投影有固定偏差，必须走引擎投影；角点逐个取高；
  字符串探测只碰类型数组成员；认领态自画白线。
- 日志：启动行 + 首次命中（宽/高/光标/基点）+ 每次
  `deploy: plots=/dropped=`、`deploy: fired/timeout`。
- ini：`Enable/AutoDeploy/DeployTimeout(5~300s)`，
  改后重启；dist 与游戏内 ini 同步；构建零警告。
