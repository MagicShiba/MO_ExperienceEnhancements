# 智能中键

背景：README“智能中键计划”——中键拖动下单（巡逻圈/散开/阵型/砍树/模糊选目标），
快捷键可改到其它键位。铁律（AGENTS.md）：禁本地直调改模拟的引擎函数，
所有模拟变更走标准事件（Mega/Connect/Commit）广播；只读查询 + 渲染面绘制安全。

触发互斥（松开瞬间归属）：裸中键=智能下令（点按自适应/划线散开），
Z+中键=巡逻，Ctrl+Z+中键=砍树，Ctrl+中键无Z=模糊，Shift+P=心控收敛。
键位正名：红警2 左键选中+下令（移动/攻击/进驻），右键取消/拖拽平移镜头，
中键原版无功能（手册与 StrategyWiki 双确认）。

## 快速砍树，模糊攻击

- 新建 OrderUtil（下单模块共享：PatrolCircle/AirSpread/TreeChop/FuzzyAttack）：
  `OU_WhatAmI/OU_Enqueue/OU_CellValid/OU_MouseCell(Px)/OU_PtrAlive(Raw)`；
  地址全只读：OutList `0xA802C8/0xA802D0/0xA802D4/0xA83A54`（SIZE=111/CAP=0x80），
  Frame `0xA8ED84`，选中 `0xA8ECBC/0xA8ECC8`，本家 `0xA83D4C+0x30`，
  Display `0x87F7E8`，Fetch_ID `0xB0E840/0xB0E844` 二分存活校验（fail-open）。
  事件编码：`Mega 0x04 ctor 0x4C6860`，`Connect 0x2A 0x4C6780`，
  `Commit 0x2B 0x4C66C0空载荷`；Misson Move=2 Attack=1（禁 Action=5）。
- PatrolCircle 重写（640行）：删 `0x639740` 直调关环（联机分叉教训），
  改原生两阶段——逐点 Mega（`Follow=Dst`）+ 全员 Connect-only 合环；
  16 节点弧长重采样；框选 skew 改固定矩阵。
- AirSpread 瘦身（-261行走 OrderUtil）：恒飞 `Aircraft==2`，
  地面 `MZ@1460==9` 主、`ST@1596==4` 兜底；64 节点散开。
- 新建 TreeChop（Ctrl+Z+中键，选中地面单位强制攻击树木）：
  `CellClass::GetTerrain 0x47C550` 直取，TerrainType 数组 `0xA8E318` 自校准，
  ID 以 `TREE*/TIBT*` 开头、排除 VEINTREE/岩石/箱子；
  `Range 2~16默认4`（游戏内 ini 用 6），`IsPlanningEvent=1` 排进路径点；
  Ctrl 按住时巡逻圈让路。
- 新建 FuzzyAttack（Ctrl+中键无Z，蜘蛛类难选中目标）：
  `CellClass::FindObjectOfType 0x47C4D0` 取链头 + `NextObject+0x30` 走链
  （64步，指针+WhatAmI双守卫）；Owner 双选中单位自校准，失败放弃绝不错击；
  `SquadSize=4` 集火分组；`IsPlanningEvent=0` 直接下令。
- BuildQueue 加 pev 抓包（`pev: t=` + 前48字节hex）：对照原生巡逻建圈/
  关环/提交的真实 Mega/Connect/Commit 序列，逐字节对拍我方构造。
  详见 notes/BuildQueue参考.md。
- 构建.bat 加 TreeChop/FuzzyAttack/OrderUtil（mingw32无CRT禁memmove）。

## 中键智能下令（点按自适应/划线散开/落点转换）

- 动因：裸中键原来只发移动令（点民房不进驻），Ctrl+中键模糊只发
  攻击令（点民房摧毁）；划线/点空地落点压建筑上时走过去再转攻击。
  目标：与左键下令同自适应。
- 逆向（tools/disasm.py 实证 gamemd.exe）：
  `DecideAction 0x692610` 只读（全范围无事件构造/OutList 引用；
  thiscall ECX=Display，栈 (cell*, obj, 1)，EAX 回 Action）；
  `FootClass::Active_Click_With 0x4D74E0` 跳转表 `0x4D7D04/0x4D7CD0`：
  Move1→idx0、Enter3→idx2(Mission7 载具)、Attack5→idx4(Mission1)、
  Capture9→idx5(Mission8，步兵进驻民房原生即此，0x51E6A8 实证）、
  Repair11→idx6(Mission9)、Sabotage16→idx7(Mission17)、
  GuardArea26→idx8（民房 Mission17 否则 AreaGuard11）。
  进入类布局 Target={0,0}+Destination=目标对象（AutoLoad §11 同构）。
- 实现（联机安全：只读查询 + 标准事件；不调
  ObjectClickedAction/ClickedMission）：
  OrderUtil：`OU_MouseCellTarget`（格+点中对象）、`OU_MouseOverObject`
  （vtbl+0x74；Unit 0x73FD50/Infantry 0x51E3B0 双确认）、`OU_DecideAction`、
  归属自校准（`AS_CalOwner`，FuzzyAttack 同式，日志 `own=mine/hN/?`）。
  AirSpread：终点有对象→全局 Decide + 逐单位能力过滤
  （同任务下单/会移动跟随/分歧无操作；未知动作无操作；Repair 等不转发）；
  全局 NoMove 时退回逐单位判定；护驻军（建筑可进驻则攻击改移动）；
  空地→散开（点按螺旋配额/划线弧形）；落点转换（`AS_Queue` 内，
  地面单位落点压建筑按直接下令，空军除外，护航不转回攻击）；
  终点有对象永不散开（0=散开/1=已下单/2=无操作），移动散开跳建筑中心格。
- 陷阱（均已避开）：① vtbl+0x1A4 是 AssignPlanningPath
  （Unit/Infantry 同 0x4DC810），不是 ObjectClickedAction；
  ② 0x4AE750 是计划路径记录，不是下单遍历；
  ③ 已发事件不可用队列余量判断（排空后 fallthrough 会被弧形覆盖）。
- 日志：仅启动行（`airspread: ON`）；诊断时临时加行，用完即删，
  不留常规日志（教训：试错期日志最多时一次点击十几行）。
- ini 无新键（注释已改智能下令），dist 与游戏内 ini 同步；构建零警告。

## Shift+中键范围智能（`src/SmartArea.cpp`，`[SmartArea]`，0.2.114d）
- 手势：按住 Shift 点按/划线→先松中键→再松 Shift 执行；按住显示范围框。
  点按=单块，划线=沿轨迹各节点逐块挑目标（去重，松开格点中排首）。
- 决策：逐单位 `MouseOverObject`，攻击/进入/进驻/占领才下单，
  移动/未知跳过（不下移动令，分不到的待命）。
  分组与模糊同义：每目标首轮 Squad 个，剩下找最近可处理目标加入。
- 仲裁：须无 Ctrl/Z（含 Ctrl+Shift+中键归模糊，含 Z 归巡逻/砍树）；
  关或坏键则 `ClaimsMiddle` 回假，组合中键回落裸中键（AirSpread 问它让路）。
  原生 Shift（多选/排路点）碰不到中键；多选时别碰中键。
- ini `[SmartArea]` 早已预留（两边 ini 都有），只补了 AirSpread 行注释与 Hotkey.md。
- 陷阱：认领函数含主键状态，松开瞬间主键已抬起则认领必掉，
  松开边必须用不含主键的组合判定（与模糊同式），否则永远不执行。
- 根因：Shift 按住时部分目标问出来是 ToggleSelect(8，加选语义)，
  真光标被盖住。修法（只读，不写键态）：光标优先 + fallback 规则表
  （非本家载具/飞机/步兵对非建筑强攻、工程师对建筑占领、
  步兵对自家载具进入、本家跳过），Owner 双单位自校准。
  非工程师步兵对建筑留待命，松手重判（0.2.118d→122d）。
- 0.2.124d：生效目标短暂标记（5x5，约 90 轮淡出，下令瞬间冻结
  参考点贴图）；进驻均分（步兵对建筑按 Capture，不管 SquadSize，
  第0轮按建筑轮转均分）。
- 0.2.128d：标记换成规划线（用户要的）：按住时单位→目标细线，
  Shift 绿/Ctrl 红，松手即消。端点走 OU_GetCoords（vtbl+0x48，
  反汇编 0x4DDED0 内同槽取坐标实证 + 范围校验兜底），投影与框同系
  （leptons，1 格=256，忽略高度）。预览只看当前块（终判按整轨迹，
  划线时预览≠终判，属实告知），SA 限 64 单位/128 线、换格或 400ms
  刷、80ms 节流；FA 同式分组镜像。命中标记全套拆除。
- 0.2.129d：预览改走快照+分配（与终判同一套输入同一套规则，
  发令/记线双 sink，终判松手重扫一次），划线预览即终判。
  预览截断前 64 单位/前 96 目标/128 线（终判全量），仅显示差异。
