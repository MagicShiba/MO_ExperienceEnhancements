# 智能中键

背景：README“智能中键计划”——中键拖动下单（巡逻圈/散开/阵型/砍树/模糊选目标），
快捷键可改到其它键位。铁律（AGENTS.md）：禁本地直调改模拟的引擎函数，
所有模拟变更走标准事件（Mega/Connect/Commit）广播；只读查询 + 渲染面绘制安全。

触发互斥（松开瞬间归属）：裸中键=散开，Z+中键=巡逻，Ctrl+Z+中键=砍树，
Ctrl+中键无Z=模糊，Shift+P=心控收敛。

## 快速砍树，模糊攻击

- 新建 OrderUtil（下单模块共享：PatrolCircle/AirSpread/TreeChop/FuzzyAttack）：
  `OU_WhatAmI/OU_Enqueue/OU_CellValid/OU_MouseCell(Px)/OU_PtrAlive(Raw)`；
  地址全只读：OutList `0xA802C8/0xA802D0/0xA802D4/0xA83A54`（SIZE=111/CAP=0x80），
  Frame `0xA8ED84`，选中 `0xA8ECBC/0xA8ECC8`，本家 `0xA83D4C+0x30`，
  Display `0x87F7E8`，Fetch_ID `0xB0E840/0xB0E844` 二分存活校验（fail-open）。
  事件编码：`Mega 0x04 ctor 0x4C6860`，`Connect 0x2A 0x4C6780`，
  `Commit 0x2B 0x4C66C0空载荷`；Misson Move=2 Attack=1（禁 Action=5）。
- PatrolCircle 重写（640行）：删 `0x639740` 直调关环（联机分叉教训），
  改原生两阶段——逐点 Mega（`Follow=Dst`）+ 全员 Connect-only 合环；
  16 节点弧长重采样；框选 skew 改固定矩阵。
- AirSpread 瘦身（-261行走 OrderUtil）：恒飞 `Aircraft==2`，
  地面 `MZ@1460==9` 主、`ST@1596==4` 兜底；64 节点散开。
- 新建 TreeChop（Ctrl+Z+中键，选中地面单位强制攻击树木）：
  `CellClass::GetTerrain 0x47C550` 直取，TerrainType 数组 `0xA8E318` 自校准，
  ID 以 `TREE*/TIBT*` 开头、排除 VEINTREE/岩石/箱子；
  `Range 2~16默认4`（游戏内 ini 用 6），`IsPlanningEvent=1` 排进路径点；
  Ctrl 按住时巡逻圈让路。
- 新建 FuzzyAttack（Ctrl+中键无Z，蜘蛛类难选中目标）：
  `CellClass::FindObjectOfType 0x47C4D0` 取链头 + `NextObject+0x30` 走链
  （64步，指针+WhatAmI双守卫）；Owner 双选中单位自校准，失败放弃绝不错击；
  `SquadSize=4` 集火分组；`IsPlanningEvent=0` 直接下令。
- BuildQueue 加 pev 抓包（`pev: t=` + 前48字节hex）：对照原生巡逻建圈/
  关环/提交的真实 Mega/Connect/Commit 序列，逐字节对拍我方构造。
  详见 notes/BuildQueue参考.md。
- 构建.bat 加 TreeChop/FuzzyAttack/OrderUtil（mingw32无CRT禁memmove）。

## 筛选心控单位，快捷键调整

- 新建 MindSelect（Shift+P 点按，结尾选中只剩心控单位）：
  原生 Shift+P 也会全选故必须过滤；上升沿跑单轮收敛——屏内
  `TacticalSelectables 0xB0CEC8`（500项 `{Object*,X,Y}`）收心控经原生
  `Select=vtable+0x14C` 加入，`CurrentObjects 0xA8ECB8(+4/+8/+16)` 去杂
  （心控前移、非心控清 `IsSelected+0x83`），两处无心控不动；
  `IsMindControlled 0x7105E0` 纯读（`[ecx+0x2C0]||[ecx+0x2C4]`）；
  偏移 `IsAlive+0x90/InLimbo+0x81/Health+0x6C`；选中是本机UI无模拟事件；
  零日志。`KeyboardMD.ini: CursorCheat=592→0` 解绑（原行注释保留）。
- 快捷键人类可读化（Hotkey.md 新建，照 AutoLoadDev `Hotkey=Ctrl+D`）：
  新增 `OU_Hotkey { vk, mods, extra[4], nExtra, disabled }`，
  `OU_ParseHotkey` 纯语法 + `OU_KeyDown/OU_ModsDown/OU_ExtraDown/OU_HotkeyDown`
  判定 + `OU_ReadHotkey` 读取；修饰大小写无关、`+/空格/Tab` 分隔，
  多键末位主键、鼠标 `Middle/MMB/LMB/RMB/X1/X2`，`None/Off/Disabled` 禁用，
  纯数字老 `TriggerVK` 兼容；缺键/坏串留默认。
  默认：巡逻 `Z+Middle`、散开 `Middle`、砍树 `Ctrl+Z+Middle`、
  模糊 `Ctrl+Middle`、心控 `Shift+P`。
  5模块迁移，删 `TriggerVK/RequireZ/ZVK/CTRLVK/MODVK`；dist 与游戏内 ini 同步。
- `;` 注释剥离统一到加载层：ini 接口不剥行尾注释，
  新增 `OU_ReadString`（读串→截 `;`→去两端空→缺键填def，无CRT），
  `OU_ReadHotkey` 改走它；MsgFont 字体名×2/超武字体名/MaxWidth、
  VecText 字体名 5处裸读全改走它；`ResolveFontFace` 用时截断删除
  （留有界拷贝+空指针守卫）；数字项（Int 接口遇 `;` 自停）不受影响。
  全 src 只剩 `OU_ReadString` 内一处裸读；构建零警告。
  注：notes/VecText顶栏与简报.md“排查”节 FontFace 条目的旧方案
  （ResolveFontFace 用时截断）已被此取代。
