# 智能中键

中键拖动下单：巡逻圈/散开/阵型/砍树/模糊选目标，快捷键可改。
铁律：模拟变更只走标准事件（Mega/Connect/Commit）；只读查询 + 渲染面绘制安全。

触发互斥（松开瞬间归属）：

- 裸中键=智能下令（点按自适应/划线散开）
- Shift+中键=范围智能（可改单键）
- Z+中键=巡逻；Ctrl+Z+中键=砍树；Ctrl+中键=模糊；Shift+P=心控收敛

左键选中/下令，右键取消/拖镜头；中键原版无功能。

## OrderUtil（共享）

- 只读：`OU_WhatAmI/OU_Enqueue/OU_CellValid/OU_MouseCell(Px)/OU_PtrAlive(Raw)`。
- OutList `0xA802C8/0xA802D0/0xA802D4/0xA83A54`（SIZE=111/CAP=0x80）；
  Frame `0xA8ED84`；选中 `0xA8ECBC/0xA8ECC8`；本家 `0xA83D4C+0x30`；
  Display `0x87F7E8`；Fetch_ID `0xB0E840/0xB0E844` 二分存活校验（fail-open）。
- 标准事件：Mega `0x04` ctor `0x4C6860`；Connect `0x2A` `0x4C6780`；
  Commit `0x2B` `0x4C66C0` 空载荷。Mission Move=2、Attack=1（禁 Action=5）。
- 规划线端点存世界坐标，绘制期投影；缓冲区为 `OU_PrevLine`。

## PatrolCircle

- 两阶段：逐点 Mega（Follow=Dst）+ 全员 Connect-only 合环；16 节点弧长重采样。
- 框选 skew 用固定矩阵。

## SmartOrder

- 恒飞 `Aircraft==2`；地面 `MZ@1460==9` 主、`ST@1596==4` 兜底；64 节点散开。
- 终点有对象：`DecideAction 0x692610` 只读 + 逐单位能力过滤
  （同任务下单/会移动跟随/分歧无操作；未知动作、Repair 等不转发）。
- `FootClass::Active_Click_With 0x4D74E0`：Move1→0、Enter3→2(Mission7)、
  Attack5→4(Mission1)、Capture9→5(Mission8)、Repair11→6(Mission9)、
  Sabotage16→7(Mission17)、GuardArea26→8（民房 Mission17，否则 AreaGuard11）。
- 空地散开：点按螺旋配额/划线弧形；落点压建筑时地面单位直接下令，空军除外；
  护航不转回攻击。终点有对象永不散开。
- 预览线：起点取单位中心（保留 Z）；终点取格中心地表高度（地形+桥面），
  与空军高度无关。`OU_PrevPushCell` 不再区分 fly。
- 避坑：`vtbl+0x1A4`/`0x4AE750` 不是下单函数；已发事件不用队列余量判断。

## TreeChop

- Ctrl+Z+中键，选中地面单位强制攻击树木。
- `CellClass::GetTerrain 0x47C550`；`TerrainType 0xA8E318` 自校准；
  可砍目标按 ID 前缀名单 `g_TcChopPfx`：`TREE*`（树）、`TRFF*`（红绿灯）、
  `SIGN*`（交通标志）、`LT_GEN*` / `LT_EUR*` / `LT_SGN*`（路灯，含带牌路灯）。
  全是 `Armor=tree` 的可摧毁地形。`TIBTRE01~03`（矿柱，`Immune=yes`）和
  `VEINTREE`（`IsVeinhole`）不在名单内 —— 无敌目标打不掉，派兵过去只会白跑；
  `POLE*`、`SPKR01` 同样是 `Armor=tree` 但暂未纳入，需要时加进 `g_TcChopPfx` 即可。
  `Range 2~16`（dist 默认 6）。
- 单位过弹头关：**只看弹头有没有写 `Wood=yes`**，别的都不看。
  没武器 / 没写 `Wood=` / `Wood=no` 的留在原地。`[TreeChop] WoodCheck=0` 可整体关掉。
  判据全从引擎的 rules INIClass 现读（类型 `GetWeapon` 虚表 `0x3F8` → 武器节
  `Warhead=` → 弹头节 `Wood=`），不猜结构偏移；武器级结果有缓存。
  **别拿 `Verses` 第 7 项（wood）反推**：地形的 `Armor=tree` 走 `[ArmorTypes]` 映射，
  自定义护甲一加就跟"能不能拆木结构"脱节，算出来是反的（`SA` 20% → 判能砍、
  `GUARDWH` 40% 也判能砍，可 GI 打不掉树、GGI 打得掉）。
- 坑一：`OU_StrOk` 只认大写，而 MO 的武器 ID 是驼峰（`MissileLauncher`、`120mm`），
  拿它验 ID 会把整把武器判成"读坏了"→ 一律不能砍。类型 ID 用 `TC_IdOk`（可打印即可）。
- 坑二：**INIClass 按节名指针缓存上一节**（`obj+4` 指针、`obj+8` 节数据，只比指针）。
  弹头节名来自栈缓冲时，同一地址换个名字会命中上一次的节。改成名字池
  `TC_SecName`：一个名字一个固定地址，缓存命中也是命中的同一节。
- 单位/树按 max 轮转全覆盖：`k % nu / k % nt`；`IsPlanningEvent=1` 排队。
- 画框用 `CoordsToClient 0x6D2140` 投影格线角点（逐角取高）。

## FuzzyAttack

- Ctrl+中键无 Z，用于蜘蛛类难选目标。
- `CellClass::FindObjectOfType 0x47C4D0` 取链头，`NextObject+0x30` 走链
  （64 步，指针 + WhatAmI 双守卫）；Owner 双选中单位自校准，失败放弃。
- `SquadSize=4` 集火分组；`IsPlanningEvent=0` 直接下令。

## MindSelect

- Shift+P 点按，结尾选中只剩心控单位；原生 Shift+P 会全选，必须过滤。
- 屏内 `TacticalSelectables 0xB0CEC8`（500 项 `{Object*,X,Y}`）收心控，
  原生 `Select=vtable+0x14C` 加入；`CurrentObjects 0xA8ECB8(+4/+8/+16)` 去杂。
- `IsMindControlled 0x7105E0` 纯读（`[ecx+0x2C0]||[ecx+0x2C4]`）；
  偏移 `IsAlive+0x90/InLimbo+0x81/Health+0x6C`。
- `KeyboardMD.ini: CursorCheat=592→0` 解绑。

## 快捷键

- `OU_Hotkey { vk, mods, extra[4], nExtra, disabled }`；`OU_ParseHotkey` 纯语法；
  `OU_KeyDown/OU_ModsDown/OU_ExtraDown/OU_HotkeyDown` 判定；`OU_ReadHotkey` 读取。
- 修饰大小写无关，`+/空格/Tab` 分隔；多键末位主键；鼠标
  `Middle/MMB/LMB/RMB/X1/X2`；`None/Off/Disabled` 禁用；纯数字 TriggerVK 兼容。
- 默认：巡逻 `Z+Middle`、散开 `Middle`、砍树 `Ctrl+Z+Middle`、
  模糊 `Ctrl+Middle`、心控 `Shift+P`。
- `;` 注释在加载层剥离：`OU_ReadString` 截 `;`、去两端空、缺键填默认。

## SmartArea（Shift+中键范围智能）

- 手势：Hotkey 点按/划线，松开执行；点按=单块，划线=沿轨迹逐块环扫
  （去重，松开格点中排首，上限 64 节点）；按住显示范围框 + 规划线。
- 决策：单位固有光标 ignoreForce=1；攻击/进入/进驻/占领才下单，移动/未知跳过。
  不用 ignoreForce=1 会被物理 Shift 污染成 ToggleSelect(8)。
- 进楼限数：自家楼工程师修掉血楼只派 1 人，满血跳过；士兵进驻不限数。
  非自家楼工程师占无主/中立科技按楼限 1；工程师对中立民房只维修。
  士兵进驻中立民房轮转均分；敌楼强占与拆除 Squad；占车/偷车按目标限 1。
- 判定：中立 `House->Type(+0x34)->MultiplayPassive(+0x1A6)`；
  民房 `TechnoType->TechLevel(+0x634)==-1`；工程师 `InfantryType+0xEC3`
  或 29/11 光标；建筑类型 `BuildingClass+0x520`。
- 排队：`IsPlanningEvent=1` 追加路径点，否则直接下令；脏键松后重判；
  超 300 轮丢弃。仲裁：须无 Ctrl，Z 不禁；关/坏键回落裸中键。
- 重判口径：单位 busy 与目标已派（占车/修楼/中立科技按目标限 1）标记随快照走
  —— 在 `SA_Snapshot` 里清，`SA_Distribute` 不清。同一快照会在“留待命 → 松键
  再判”以及“同一轮内连判两次”时被重复分配，若每次分配都清目标已派，按楼限 1
  的目标会再挤一个人（现象＝最后那个目标分到两人）。待发令（`g_SaPendCount`）
  同理只在取新快照时清，终判不清，否则 OutList 满时已标 busy 却没发出去的单位
  既不会再派也不会动。
- ini：`Enable/Hotkey/Range/SquadSize`。

## 敌我识别 (全下单模块共用)

- `OU_OrderSide(unit)`: 0=不可控（敌人/中立/读不到）1=自家 2=盟友。
  判据 `OFF_OWNER` + Houses 数组成员校验 + `IsAlliedWith`（含自己）；
  中立看 `House->Type->MultiplayPassive`。心控单位 Owner 已被引擎改成控制方，
  算自家（CaptureUnit 里 `SetOwningHouse` 实证）。
- 盟友放行要过两道闸，任一不过都静默丢弃（不下令、预览也不画线）：
  ① `OU_OrderAt`: 目标格与单位当前格切比雪夫距离 ≤ `OU_ALLY_MOVE_CELLS`(2)；
  ② 60 秒滚动窗口内最多 `OU_ALLY_USE_MAX`(3) 次 `OU_OrderTake`。
- 为什么两道：盟友只用来「AI 单位占位挡路挪一下」，不是免费遥控；距离短 +
  频率低，等于手动微调而不是调兵。配额是**任意 60 秒内**不超过 3 次（环形记
  最近 3 次时刻，最旧一条滑出窗口才放行），不是每分钟整点清零。
- `OU_OrderAt` 是纯查询（预览每帧都问，不能有副作用）；`OU_OrderTake` 只在
  **真的入队那一刻**调一次（自家不占配额）。超距/超频的尝试不计数。
- 落点：SmartOrder 按下快照滤 0、`SO_Queue` 门控 + 两个入队点 Take、对象令
  两处任务循环按格距门控 + 入队点 Take；
  DeployPreview 快照/地基扫描/移动排空/到位跟踪全部只认自家（盟友车不替你
  展开，单选盟友车时本模块不认领，落到 SmartOrder 的 2 格挪动）。
  其余中键模块（SmartArea/PatrolCircle/TreeChop/FuzzyAttack/AttackMove）
  只收自家单位。

## DeployPreview（基地车展开预览 + 自动展开）

- 基地车 `[General] BaseUnit=AMCV,SMCV,PCV,FMCV`，物理中键按住画黄框
  （落点地基外框，引擎投影吸格线）+ 目标格细框；松手车到位自展。
- 锚点：基点=光标格+(大地基-1,-1)；车移动目标=基点+(1,1)；
  落点=TryToDeploy 公式（`0x7393C0`）。
- 认领：开关+AutoDeploy、物理中键、无 Z/Ctrl、选中含可展开单位；
  Shift+Middle 时优先于 SmartArea；按下瞬间快照。
- 分配：单车起点=终点；多车 `DP_AssignPoint` 螺旋平铺；划线
  `DP_AssignLine` 弧长均分；Shift `DP_AssignStraight` 锁轴。其它单位按配额散开。
- 下令：移动 `MegaMission(Move)` 排队滴发；到位轮询发 Deploy 事件 `0x9`
  （ctor `0x4C65E0`）；死车/换边/超时/无处可铺放弃。
- 绘制：白轨迹线 + 每车黄框 + 目标细框；`DP_CornerLep` 走
  `CoordsToClient 0x6D2140`；每角 Z 取框内格 `GetFloorHeight 0x47B3A0`。
- ini：`Enable/AutoDeploy/DeployTimeout(5~300s)`，改后重启。
