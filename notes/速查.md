## 编码约定
- `UtoA/HtoA` 返回**写入长度**（`pos += ...`）；`AppendCStr/AppendCh/AppendInt` 返回**新绝对位置**（`pos = ...`）。混用静默截断。
- 引擎地址/结构偏移只许写 `src/EngineAddr.h`，.cpp 里不许本地 `#define`（曾分叉出 `OFF_HOUSE_MONEY` 0x2F0/0x30C）。
- 手绘几何 `OU_Put/OU_Line/OU_Box`；锁面 `OU_SurfLock/Unlock`；事件清零 `OU_EvClear`；根目录 `GtGameDir()`。
- 下令/选中走 `OrderUtil`：`OU_FireMega/OU_MakeMega`、`OU_ObjTgt`(失败 -1)/`OU_CellTgt`、`OU_InVec/OU_IsUnit`、`OU_CellFloorZ`。
- 查未使用静态函数必须 `g++ -c -o /dev/null`（`-fsyntax-only` 不报 `-Wunused-function`）。
- 注释只写"现在是什么/为什么必须这样"；版本号只在 `MOE_VERSION`；细则进 `notes/`，文件头 3~5 条约束 + 指向。
- 纯注释改动验证：重编后 `dist/MOExperience.dll` sha256 必须与改前一致（无 -g）。

## 地址速查
- `0xA8B238` GameMode(3 LAN/4 Internet/5 Skirmish/0 战役)；`0xA8B230` Scenario；`0xA8ED5C` ScenarioStarted；`0xA8ED84` 帧号；`0xA8ED80` IsFocused
- `0xA8EB60` GameSpeed；`0xA8B55C` 每帧时间；`0x887350` TimeLeft(1/60s)；`0xA9FAB0` 载入相位；`0xABCD40/44/48/4C` 帧数/帧率
- **`GtTickNow()` 的单位是 16ms 不是 1ms**（= `timeGetTime() >> 4`，`0x6C8C40` 里 `shr eax,4`）。
  当毫秒用会把所有时间线拉长 16 倍（2.5s 变 40s）。要毫秒就 `GtTickNow() * 16u`；
  `GtClockNow()` 同一把尺子。
- IAT：`0x7E1484` PeekMessageA、`0x7E1530` timeGetTime
- HouseClass::Money `+0x30C`；IsHuman `+0x1EC`；HouseType `+0x34` → MultiplayPassive `+0x1A6`
- `CellClass+0x12C` bit3 = Mapped（已揭示）。判黑幕读这一位，**别调** `0x487950`/`0x586360`（内含 `idiv [0xABDE88]`，早期除零）
- 存/读/删界面：状态机 `0x558DD0`（`this+4` 页面 1读/2存/3删，`this+0x18` 动作）；
  对话框 `0x622650(ecx=模板 183/692/693, edx=DlgProc 0x558a30/0x558b90/0x558cb0)`；
  `GetWindowLong(dlg, DWLP_USER)` 就是那个屏幕对象。存档页加"载入"= 写 `ctx+4=1`、
  `ctx+0x18=0x40F`；**空闲动作是 -1 不是 0**（写前核对 `ctx+4==2 && ctx+0x18==-1`），
  且动作分派只按页面走（页面1=读档/2=存档），故必须同时改页面，否则会执行一次存档；
  **别直连 `LoadGame 0x67E440`**
- `0xA83D4C` CurrentPlayer（本机，可写）；`0xAC1198` Observer（只读）

## 音效（`src/misc/SoundFx.cpp`，详见 `notes/天气.md` §4）
- 名字→下标 `0x7514D0`（fastcall ecx=名字，大小写不敏感，找不到 -1）；表 `0xB1D378`，**下标 = sound.ini `[SoundList]` 序号**。
- 播放 `0x750920` fastcall(ecx=idx, edx=pan 0..0x4000, 栈=音量 float, 栈=AudioController*)，`ret 8`；**音量是倍率不是绝对值**（`0x4061D0` 里乘 sound.ini 的 Volume，1.0 = 原音量）。`PlayAt 0x7509E0` 要世界坐标。
- 循环音必须自持 `AudioController` 才能停：`{Event,Stamp,EventType,AudioIndex,Unused}`，**AudioIndex 必须 = `0x87E294`**，否则 `End/Stop` 认不出自己的事件、空转。
- `AudioController::End 0x405FD0` 按 `(Stamp, EventType)` 核对事件是否还活着 → 事件已被引擎销毁时补一次 End 是安全的；末尾会把 Event/EventType 清零。
- 名字写错 = 静默不发声（不崩），只缓存**成功**的解析；失败要退避重试，别每帧扫几千条。
- **循环音消失：引擎会回收事件，且不会交回来 → 只能在调用方兜底。** 回收标记固定一组：
  `[ev+0x1C]=4`、`[ev+0x138]`(Stamp) 清 0、`[ev+0x278]`(归属) 清 0、`[ev+0x18]|=1`。
  归属一清，外面持有的 `AudioController` 永远对不上，`End` 停不了、引擎也不重发。
  日志死相 `weather: snd ... st=4 flags=1 belong=0 owner=0`。
- **不要在引擎里救它**（v0.2.687 起 `AudioLoopFix.cpp` 与那六个钩子已整个删除；留着时也只写日志、不改状态）。
  试过并全部失败的四处：`0x4055C0` 替它重播、`0x40468F` 保住事件、`0x405A0F` eax 改 1、
  `0x4059F0` 改回状态 1、`0x405817` 对齐 controller —— 雨声照死，还会改掉引擎自己
  循环音的行为（rebind/revive 大量落在引擎环境音上）。判"补丁有没有生效"只看**它自己的
  日志字样有没有出现**，不能靠"声音还是不对"反推。
- **唯一管用的是提优先级**：`Sfx_LoopStart` 起声后写 `VocClass+0x40`(Priority)=3(High)
  —— sound.ini 里雨声 `Priority=low`、风缺省(`Lowest`)，而 voice 分配 `0x404E20` 直接把
  Priority 当"能扫几档"的入参（`0x4045F5`），最低档最先被挤掉。
  **实测（0.2.686 日志）：事件一直 `st=3 belong=1`、`loop died` 全程 0 次；683~685 同场景全是 `st=4 belong=0`。**
  v0.2.687 起删掉"每帧复查重起"与 `Sfx_LoopAlive`（从未触发过），`SoundFx.cpp` 只留 4 行写 Priority。
- 引擎音频调查（事件池/采样池/voice 分配/触发系统四条路径）独立在 `notes/音频.md`；`notes/天气.md` 只留"天气怎么调"。
- `Sfx_LoopAlive` 判据：总开关 `0x87E2A0`（为 0 时事件池已整块 free，先看它再解引用）→
  `Event` 非空 → `[ev+0x278]==ctrl` → `[ev+0x18]` bit0/bit5 → 状态 != 4。
  **不比 Stamp**：引擎每续一轮都改写它，拿它比会一直误判成"死了"。
- 事件状态 `[ev+0x1C]`：0 初始化 / 1 待取采样 / 2 等截止 / 3 已提交在播 / 4 已结束；
  跳表 `0x4059D0`。状态 1 由 `0x404540` 那套每帧循环处理（前提 `[ev+0x158]==0`）。
  **状态 3 对被 controller 认领的事件直接 ret**，所以"看状态判活"永远判活。
  轨迹日志按 (事件,Stamp) 认人，死亡会清 Stamp，**恰好记不到"变 4"那一跳**。
- 混音器 `0x404320` 按 `sound.ini` 的 `Limit` 每帧掐超额实例（`[voc+0x44]` 计数 vs
  `[voc+0x48]`），掐的时候同样置 4。

  会重复消耗采样列表并叠音。判"播完了"不能用 `[ev+0x148]==0`（`0x40554E` 播完会写回）。
- `VocClass` 相邻字段易读串：`+0x48` = `Limit`，`+0x4C` = `Loop=`；`Control` 的 Loop
  位是 **0x01**（Random 0x02 / All 0x04 / Decay 0x40）。

## 主循环 / 限速
- ESC 菜单分页：左栏页名下标 = `EDIT_PAGE_*`（GUI0/文本1/显示2/快捷键3），页表走 `Esc_PageAt(sel)`；
  判"非文本页"一律写 `page != EDIT_PAGE_TEXT`（别写 `== EDIT_PAGE_GUI`，否则新页的
  数值/滑条编辑不生效）；组间距首组判据用行下标 `i != 0`，不是 `item != 0`。
  GUI 页与显示设置页共用 item 枚举/段名表/`Esc_ApplyGui`，只有行表不同。
- 改键（`EG_HOTKEY`）：**热键不能走 `Esc_QueueRaw`**——它是模块里的运行期状态，
  排队的话这一局不生效；必须 `Esc_WriteIniRaw` 立即写盘 + 调 `XX_ReloadHotkey()`，
  取消回滚靠打开菜单时备份的 ini 原串（`s_HkBak`）。捕获用 16ms 定时器扫
  `GetAsyncKeyState`，**全部松开才结算**（否则 Ctrl+Z+Middle 攒不齐）；进捕获先把
  已按住的键快照掉，否则点这一行的左键会进组合。反写用 `OU_HotkeyText`。
- `0x55D360` MainLoop；**ESC 菜单打开时主循环全停**，CPU 100% 来自 PeekMessageA 空转 → 限速只能落 PeekMessage 路径，按 pump 次数判定。
- FrameCap：一个模式只能一个节拍器；取到消息那次不能等；QPC + `MsgWaitForMultipleObjects` + `timeBeginPeriod(1)`。
- 写 `0xA8EB60` 非 0~6 必崩（`GetAnimSpeed 0x5FB2E0` 地址越界）；自定义 FPS 只能自持变量，联机禁用（广播的是档位 int）。
- Syringe 钩子返回**绝对跳转地址**，返回 0 = 重放原指令；速度钩点 `0x55D79E`，fps 纠正 `0x55E3B5`。

## 钩子铁律
- 要画在地图里且被黑幕/迷雾盖住 → 钩 `0x6D3660` 入口（前 5B `83 EC 38 53 55`，无 rel）。
- `0x4F42F0`(prepare) 每帧 161 次 → 挂上的 Poll 自己门控（帧号变 **或** ≥16ms）。
- `0x623120` 不能挂钩（20+ 处 jmp 共享块）；装钩前跑 `python tools/hookaudit.py`：站点前 N 字节含 rel 会被原样抄进桩池且不重定位 → 必崩。
- cnc-ddraw 抢 `PeekMessageA` IAT → 每帧比对槽位自愈重挂（`FrameCap_EnsureIat`），只对 cnc-ddraw 做。
- 聊天广播只能跳 `0x55EDBF`，前置 `0xABCE18`=3，否则掩码 `0xA8D667`=0 只剩本地回声。
- 跳板指针不许兼作"本帧出口"：跳板本体与跳转目标两个变量，每帧复位。
- 引擎绘制目标 `[0x87E8A4]`；基址 `0x4114B0`；局部坐标 = 屏幕 − `ViewBounds 0x886FA0/A4`。
- `0x622396` 是 present 前最后一跳（`[0x887310]` + `call [eax+8]`）：写在它那张面上的像素**会被窗口子控件 GDI 盖住**。对话框列表这类内容只能接管控件 `WM_PAINT`，盖像素无效；反过来，子控件内容要更新只能靠对话框重画带出 `0x622396` —— 而**光 `InvalidateRect` 不够，必须紧跟 `UpdateWindow`**（这个对话框的 `WM_PAINT` 不会自己冒出来）；跨线程（心跳线程）判焦点不能用 `GetFocus()`（那是调用线程的焦点，恒 NULL），用 `GetGUIThreadInfo(0,&gi)` 的 `hwndFocus`。
- `IsPlausiblePtr` 不查可读性；崩溃定位 `obj/MOExperience.map`（基址 `0x6f200000`）。

## 性能 / 构建
- 比帧率只看 `fmed`；本 DLL 总开销约 300us/3077us（~10%）——优化前先算天花板。
- 超武侧栏 `dSWS` 拆 `swsL`/`swsB`；SSE2 与标量逐位等价，改后跑 `SwsSse2Scan`（要 `bad=0`）；"每 N 帧"节流必须再叠墙钟门。
- `GdiEnsure` 槽位已用 0/1/2/3/5/6/7/8/9，不可撞车。
- `src/` 7 个子目录（core/gui/order/sidebar/preview/perf/misc），裸名 include 靠 `build-common.bat` 的 `SRCINC`；**新增子目录必须加一条**，否则改头不重编。
- `.bat` 纯 ASCII + CRLF；起测试局走 `tools/run_test.bat`（Syringe exe 名必须双引号）。
- **体积**：链接 `-s`（去 COFF 符号表 + libgcc 的 DWARF）−187KB；编译
  `-fno-unwind-tables -fno-asynchronous-unwind-tables`（32 位 mingw 默认给每个函数发
  `.eh_frame`）−64KB。958KB→706KB，余下就是 `.text` 563K / 图标 `.rsrc` 50K /
  `.rdata` 41K / `.reloc` 32K，没有可再砍的。
- **别开 `--gc-sections`**：要配 `-ffunction-sections`，只省 4KB，而且会把 `.syhks00`
  当无用节回收 —— 钩子表没了整份 DLL 就失效；配 `-fdata-sections` 更糟，5MB 静态
  缓冲从 `.bss` 挪进 `.data`，文件直接 +5MB。
- **`__declspec(dllexport)` 不能去**：`.syhks00` 每个条目只存处理函数的**名字**，
  Syringe 靠 `GetProcAddress` 解析（66 个导出 = 61 个钩子处理函数 + DllMain 等）。
- `.reloc` 32KB 也不能去：DLL 实测被加载到 `0x67F80000`（不是首选基址），去掉就加载失败。
- `-s` 后 DLL 里没有任何符号，崩溃反查只靠 `obj/MOExperience.map`。
- 验证"零行为变化"：`-s` + no-insert-timestamp 已让产物无符号表/无 `.debug_*`，但
  **改函数名仍会让链接布局微移**（实测 `.text/.rdata/.edata` 都有字节差异），别拿整
  文件哈希当证据，按行为/日志判断。
- **别用 `git stash` 做对照实验**：本仓库有历史 stash，`push` 因路径不匹配失败后 `pop` 会误应用别的 stash（曾带出 `FullMap.cpp` 冲突 + 一堆 staged）。要对照就"复制到 /tmp + 改回来"。

## 单点结论
- 读档光照: 引擎读档时**会**用存档内嵌地图 ini 的 `[Lighting]` 写回 Ambient 三兄弟+tint
  (0x68A816), 别再用"地图原值"盖它; 场景重开只需"按现值重算一遍"
  (Light_Apply + LightConv_RefreshNow, 等价手改一次)。`0xA9FAB0` 是屏幕渐变状态机
  相位, 不是载入相位。
- **"读档后要刷一次"的触发别用字段签名/帧号倒退**: 读档后字段可能与读档前一模一样
  (存档自带 [Lighting]), 主菜单读档帧号也不倒退 (新进程)。可靠触发:
  `0x683E75` (7B `C6 05 5C ED A8 00 01` = 引擎把 0xA8ED5C "对局中"置 1, 新开图/
  读档共用; 最佳) 与 `0x559DCA` (`0x559D60` 内 `call LoadGame` 下一条, 6B
  `8B 0D 40 76 88 00`; LoadGame 全程序唯一调用点)。
- **Poll 的闸门不能当否决条件**: `0xA8ED5C`(对局中, 读档前被 0x559DAE 清 0) 或
  `0xA9FAB0`(屏幕渐变相位) 一卡, 后面所有分支连日志都没有, 静默全停 —— 而手动菜单
  改参数不查闸, 于是表现为"手动有效、自动无效"。写法: 闸门只做等待条件 + 帧数上限
  (超时硬刷), 签名保险丝放闸门之前。
- 任何"文字大小/字体"一律跟随 `[VecText]`（`VecText_ResolvedPx/FontFace/Bold` + 主字号槽 2，
  `RenderLine`+`BlitCoverage`）。模板 8pt 与按行高推导都比它小一圈；**别为字号另开 ini 开关**。
- 侧栏只能靠 `BlitSidebar 0x6A70E0` 上屏（在 present 之后）；接管后必须补 `Fm_CursorStampStrip` 烙光标。
- 超武去重会进存档 → 关总开关必须**无条件**归还一次（`s_RestoreDone`），只走 `AddCameo 0x6A6300`。
- 观战判据的"无出生点"分支要看 `Scenario+0x1180` HouseIndices 是否**整表全 -1**（选房阶段数据，
  存档不恢复）：读档进图后实测全 -1，照判会把本机当观战者，连带"观战全可见/观战不参与"全误判。
- 观战判据统一用 `Observer_LocalIsSpectator()`（`CurrentPlayer==Observer` 或任一观战槽/无出生点）；观战不参与对局，声明类功能一律跳过。**观战是整局固定身份，引擎不支持中途转玩家**，别为"切位进场"留分支。
- 载员路径点：shift = 多选显式开关；参与集合只增不减；名单用完必须 `Up_PickClear()`。
- 想加"引擎原生美术"的按钮：必须 patch 对话框过程，在**调原过程之前**建 `BS_OWNERDRAW`
  子窗口（引擎 WM_INITDIALOG 会挂 0x610CA0 子类 + 注册进 `0xAC1B00` 表），之后从同类
  按钮复制 ownerdraw 元素 `+0xB0` band。存读档页 DlgProc = `0x558B90`（前 5B `53 8B 5C 24 10`）。
  文本必须是 **CSF 键**（窗口文本被当键查 StringTable，查不到显示 `MISSING:<ANSI>`）。
- 原生按钮的**文字只在初始化时**算一次存进对象字段（`0x6102EA` → `0x734E60` → `0x623560`），
  绘制 `0x6071E0` 只读那份 malloc 副本，**`SetWindowText` 改了也不显示**。动态变字：扫
  ownerdraw 元素 `+0x04..+0x200` 找指向该宽串的 DWORD 得偏移（实测 `+0x40`），换字时用
  引擎 malloc `0x7C8E17` 分新块再改字段（销毁时引擎会 free 它，别指静态串）。
- `0x734E60` = StringTable 查找：fastcall(`ecx`=key, `edx`=out int*)，栈上两参数，**`ret 8`**；
  前 6B `53 56 8B F2 8B D9`。查不到就拼 `MISSING:'%hs'`(0x845820)，表空返回 `L""`(0x84583C)。
  要挂钩必须连 `ecx` 一起 push/pop，否则跳回 `mov ebx,ecx` 拿到垃圾、崩在初始化尾。
  CSF 里现成空串键：`GUI:Blank` / `TXT_NONE`（要"有美术没文字"时用）。
- 存读档屏幕 vtable `0x7ED2E4`：`[1]=0x559D60` 才是真读档（建 0x41C 框 → pop 屏幕栈 →
  `0x67E440` → 恢复栈深 → 销毁框）。它会释放 UI 主题资源 `0xB0FC10..0x2C`，**期间别请求重绘**。
- 存档页里点"载入"，光写 `ctx+4=1; ctx+0x18=0x40F` 不够：外层是**存档命令**（`0x4F13BD`，
  不看返回值），收尾一定 `ShowWindow(菜单, SW_SHOW)`，于是世界已换新而菜单又冒出来
  = "停在设置页/鼠标消失/要盲点"。必须在 `0x4F14BF`（5B `6A 05 56 FF D7`）改走载入收尾：
  `[ebp]=0x51e` + `xor eax,eax` + pop edi/esi/ebp/ebx + `add esp,0x614` + `ret 0x10`；
  其中 `ebp = GetWindowLong(hDlg, 8)` = DWLP_USER（`0x4F12B1`）。真载入也是这么写的。
- **ini 节名只许写一处**：环境显示组的配置合并到 `[Environment]` 一节（原来散在
  `[Weather]`/`[OreLight]`/`[LightingPreset]`/`[LightingRefresh]` 四节）。节名与跨模块
  键名统一放 `src/core/EnvIni.h`（`ENV_SECTION` / `ENV_KEY_*`），模块里只写
  `#define XX_SECTION ENV_SECTION`。合成一节后同名键会互相覆盖，所以键名一律带
  模块前缀（`LightFixEnable`/`LightMix`/`OreEnable`/`OreFactor`）。
- **读 ini 字符串一律 `OU_ReadString`**（`src/order/OrderUtil.cpp`：默认值 + 截 `;` 注释
  + 两端去空）。直接调 `GetPrivateProfileStringA` 会踩坑：本仓库 ini 的值后面常跟
  `\t;中文`，API 只裁首尾空白，返回 `"particle\t;…"` 这种串，跟 `"particle"` 永不相等
  （`DrawMode`/`CloudStyle` 曾因此永远读回默认）。整数键没事（atoi 遇 tab 停），
  **只有字符串键必踩**。整节枚举键名（`GetPrivateProfileStringA(sec, NULL, ...)`）例外。
- **`Wth_LogicDelta` 一帧只能调一次**：它更新帧号基准，第二次必定返回 0 → 粒子与
  图像帧 `dp=0`，表现为"雨雪静止"。
- 小窗口 (PiP) 改宽/高/倍率必须**立刻丢离屏面**（`PiP_InvalidateSurfs` 清 `g_RW` +
  `g_HasContent`）：`PiP_DrawOnComposite` 用 `dW = g_RW/g_ScaleNum` 反推贴窗尺寸，
  旧面配新倍率会贴出错误大小的假窗。所以 ESC 里对应的滑条必须"松手才提交"
  （`Esc_SlideDefer`）。关 `Enable` 不能关窗（`g_Show` 要保留），否则取消菜单回滚不回来。
