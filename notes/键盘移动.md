# 键盘移动 (WASD)

代码: `src/gui/UnitPanel.cpp` (`Up_KeyMovePoll` / `UP_KeyGate`)。
入口: 左下角选中面板左侧第 2 个按钮 `UP_BTN_MODE` (三条横线)，点亮 = 开。

## 1. 键位

开模式且**有可动单位选中**时，`Game::KeyboardProcess` (`0x55DEE0`) 入口把裸
W/A/S/D 的输入 DWORD 清零，原函数继续跑但查不到命令；带 Shift/Ctrl/Alt 的
组合键不碰 (Alt+A 结盟 / Ctrl+S 截图等照旧)。没有可动单位时不吞键，原版
W/S/D 仍可用。

可动 = 自己的、`IsAlive`、非 `InLimbo` 的 Unit/Infantry/Aircraft；建筑、敌方、
载具内载员不算。

## 2. 方向与格

八方向各走一格 (斜向不是两个正向相加的两格)：

| 键 | 屏幕 | 格偏移 |
|---|---|---|
| W | 上 | (-1,-1) |
| S | 下 | (+1,+1) |
| A | 左 | (-1,+1) |
| D | 右 | (+1,-1) |
| W+D | 右上 | (0,-1) |
| W+A | 左上 | (-1,0) |
| S+D | 右下 | (+1,0) |
| S+A | 左下 | (0,+1) |

## 3. 下令

对每个单位发标准 `MegaMission`，与手点右键移动同形：不调 `ClickedMission`，
不播语音。`Mission=Move`，`Destination=格`，`IsPlanningEvent=0`，每单位一次一格。

### Target 槽（索敌）

原版事件执行会 `SetTarget(事件Target槽)`，引擎"有目标时不重扫"，所以移动令
给什么目标，这一格就锁谁。给一个打不到的，单位会一路无视身边射程内的敌人。

- **射程够得着** → 原样回填，保持锁定，边走边打 (`SetTarget` 对同一目标幂等，
  炮塔不动)。
- **够不着** → 换成引擎索敌 (`GreatestThreat(THREAT_RANGE)`，虚表 0x3C4) 挑出
  的射程内目标；一个都没有才传空 (清 TarCom)。

射程自己算，不用 `IsCloseEnoughToAttack`：那条链 (0x6F7780) 在武器类型取不到时
走"武器为空"分支，返回值不反映真实射程。现用 `GetWeapon(0..2)` (虚表 0x3F8) 取
`WeaponTypeClass::Range` (`+0xB4`)，与平面距离平方比较，留一格余量给目标体积。

**只传空不行**：`SetTarget(NULL)` 确实清了目标，但引擎的自动索敌紧接着又把那个
够不着的远处目标选回来 (它仍是最"近"的敌人)，结果是一路走过去都不换目标。
给它一个射程内的目标才换得动。

玩家手动点远处敌人时的"追过去"是 `Mission=Attack`，不受影响；按 wasd 移动时
才会被换掉。

### 超程放弃

wasd 只在"到格 / 超时"时发新令，中间目标飘出射程就会一直锁着。所以按住方向键
期间 `Up_KmDropStale` 每 `UP_KM_DROP_TTL` (15 帧) 检查一次：目标还活着但打不到，
就换成射程内目标 (没有就 `SetTarget(NULL)`)。

换目标**只调 `SetTarget`** (虚表 0x3C8，`ret 4`)，不碰 `Mission/Destination/Path`。
重发移动令会把寻路重置，单位迈不开步。

不做"同一目标只清一次"的抑制：引擎会把它选回来，记死就再也清不掉。松手后目标
状态交回原版 (玩家可能刚点了远处敌人要追)。

## 4. 连按/按住

每单位记一个"上次目标格"锚点：

- 换方向: 确认窗口后从当前格起走一格，旧锚点作废。
- 同方向再按: 从锚点往前推一格，快速连点可累加。
- 按住: 单位走到锚点后才发下一格 (最短隔 `UP_KM_MIN_GAP` 帧)，频率跟着单位速度。
- **走不动** (坐标一个 lepton 都不挪超过 `UP_KM_STUCK` = 30 帧) 立刻从当前格重发
  一格，且**不带目标** —— 挂着射程内的敌人重发，单位会站着打不挪窝。
  `UP_KM_TIMEOUT` (240 帧) 只兜"坐标在动却始终到不了目标格"的绕圈情况。
- 锚点保留 `UP_KM_ANCHOR_TTL` 帧；换选/死亡/换局清掉。

方向变化 (含组合键) 有 `UP_KM_COMBO_MS` (100ms) 确认窗口：W 和 D 前后脚到达时
只发一条斜向令，不会先走一格正向再改斜向。窗口内全部松开则松手时补发一次；
斜向点按先松一个键也不会降级成单方向。

所有时间量用**帧**：引擎是帧锁定的，一帧 = 一次逻辑步进，帧率就是游戏速度。
唯一例外是 `UP_KM_COMBO_MS` —— 它量的是人的手速。

### 原版行动线

`[UnitPanel] ActionLines=1` 时强制打开引擎的 `UnitActionLines` (0xA8EB7E)，
并在每次键盘下令后调用 `TacticalClass::StartDrawActionLineTimer` (`0x70D150`，
只写本地渲染计时)，显示原版点击移动时那条单位行动线。`0` 不改游戏内设置。

## 5. 门控

聊天输入、`Game::SpecialDialog`、单机暂停、窗口失焦、Z 规划、Ctrl/Shift/Alt
按住时不下令。折叠面板、关面板、换局时自动关模式 (避免吞键没有指示)。

## 5.1 联机不启用索敌换目标

移动令本身 (MegaMission 事件) 走引擎的事件通道，联机正常。目标保留/清除只在
单机启用：

- `Up_KmDropStale` 直接调 `SetTarget`，不走事件，只改本机模拟 —— 两边目标不同
  就是分叉。
- `Up_KmIssue` 的目标槽联机下留空 (`s_KmMp = OU_IsMP()`，GameMode 3/4)，移动令
  与手点右键同形，索敌完全交回引擎。

## 5.2 读档保留开关

进局时记下地图名，与上一局相同就恢复 WASD 开关 (锚点不恢复 —— 按单位指针 + id
索引，读档后旧对象已经没了)。

地图名取 `ScenarioClass::Name` (`OFF_SCEN_NAME` = 0x1360，宽字符 0x2D 个)，
`0x686DD0` 实证由地图 ini 的 `[Basic] Name` 解析而来。读档时这个 ini 是存档内嵌
的地图，所以仍是原图名。**不能用 `FileName`** (0x125C)：读档后它是存档名。
`Name` 没写的图退到 `UIName` (0x13BA)。

"进了一局"两条一起判：`ScenarioStarted` 的 0→1 边沿，或**帧号倒退** (每局开始
`0x795234` 把 `0xA8ED84` 写 0)。读档时主循环停着，0→1 那一拍轮不到 `UP_Poll`，
只能靠帧号倒退认出来。

读不到地图名时只放弃比对；折叠态不恢复 (没有模式指示，恢复了等于"键被吞却没
提示")。
