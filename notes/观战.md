# 观战 / 多观战

## 1. 核心机制

| 量 | 地址 | 含义 |
|---|---|---|
| `HouseClass::Observer` | `[0xAC1198]` | 全局单例“真观战”房 |
| `HouseClass::CurrentPlayer` | `[0xA83D4C]` | 本机玩家房（各机不同） |

判据是 `IsCurrentPlayerObserver() = CurrentPlayer == Observer`。

## 2. 选举点：`ScenarioClass::AssignHouses` (0x687F10)

按 Color 升序遍历节点表（items `[0xA8DA78]` / count `[0xA8DA84]`），每轮建一个房：

```
0x687F4D  Observer 先清零
0x688109  仅下标 0 的节点被选中时写 CurrentPlayer
0x68813A  node->HouseIndex(+0x6F) = house->ArrayIndex(+0x30)
0x68811C  每个观战节点房都写一次 Observer
```

每建一个观战房就覆盖一次 Observer，最终只留最后一个。
只有那台机器满足 `CurrentPlayer == Observer`。

节点表字段（`NodeNameType`）：`SpectatorFlag +0x6B`（-1 为观战）、
`HouseIndex +0x6F`、`Color +0x53`。

战役（GameMode==0）走另一条路（`0x68ACE0`，按 INI 玩家名找房），不碰 Observer。

## 3. 为什么其余观察者“被击败”

观战房无单位无建筑，`House::Update`（`0x4F8E86` 起）必走
`DestroyAll` + `AcceptDefeat(0x4FC0B0)`。`AcceptDefeat` 内的观战豁免
全是“本机是真观战 / 战败的是真观战房”这类 UI 分支，假观战全走普通玩家分支。

## 4. 解法：只改本机 `CurrentPlayer`

```
if (本机确实是观战者 && CurrentPlayer != Observer) CurrentPlayer = Observer;
```

之后原版约 29 处观战分支自然命中，无需逐个挂钩。

约束：不改 `Observer`（全网一致，改它跨机分叉，波及胜负计数等模拟分支）；
不清 `Defeated(+0x1F5)`（模拟态，真观战同样为 1）。
`CurrentPlayer` 按定义各机本来就不同，对齐它不产生新分叉。
唯一例外是单机读档后的重建，见 §7。

“本机确实是观战者”判据（需 `IsHumanPlayer(+0x1EC)`，两条取并集）：

* A. 节点表中有 `SpectatorFlag(+0x6B)==-1` 且 `HouseIndex(+0x6F)==ArrayIndex` 的节点。
* B. `ArrayIndex` 不在 `Scenario::HouseIndices`（`Scenario+0x1180`）内，即无出生点。
  **但整张表全 -1 时不算数**：那是未初始化（选房阶段的数据，存档不恢复；
  读档进图后实测 16 格全 -1）。照旧判就会把单机读档的玩家当成观战者，
  连带所有"观战全可见 / 观战不参与"的分支一起误判。

## 5. 观战面板排序：人类在前、AI 在后

面板名单表 `0x884B94` / 计数 `0x884CF8`，由 `0x6A57DC` 按 `HouseClass::Array`
顺序填充。原版跳过中立、跳过 Observer 自己、跳过全部 AI。
本模块改为：排除中立 / 任一观战槽（含自己）/ 野指针，其余先人类后 AI，
组内保持数组原序。引擎每帧重算，本模块每帧重填。

## 6. 验证

双机放 2+ 观察者：每台观战机都应看到观战面板；面板内人类玩家排在 AI 前面，
且任何占观战槽的玩家都不出现在面板上。

## 7. 读档

现象：观战局存档后读档，侧栏观战面板整段消失（看不到 AI 条带与其建造情况）。

根因：读档 `LoadGame 0x67E440` → `0x67E659` → `0x67E730` → `0x6851F0`（把
`CurrentPlayer` 清 0）→ `0x689470`（反序列化 Scenario，顺带整表重建房对象）。

* 引擎**不会**重设 `Observer`（全程序只有 `0x687F4D` / `0x68811C` 两处写，都在
  `AssignHouses` 里）。读档后它要么是 0（没有观战节点），要么悬垂（地址合法、
  对象已释放）。
* 绘制端门是 `CurrentPlayer == Observer`（`0x6AA043`），不等就整段跳过；名单表
  也只在相等时才由本模块补 AI。`CurrentPlayer` 由引擎重设为**新房**，于是
  `cp != ob`，面板消失（此时判据 A/B 仍能认出本机是观战者）。

### 必须防的崩溃

`Observer` 悬垂时把 `CurrentPlayer = Observer` 写回去，下一帧引擎拿它取
`PlanningPaths` 就崩（`0x5023EA` = `0x5023B0 GetPlanningWaypointAt`）。
所以**写 `CurrentPlayer` 之前必须先校验目标还在 `HouseClass::Array` 里**
（`OB_HouseInArray`）——`IsPlausiblePtr` 不够，悬垂指针的地址是合法堆地址。

### 修法

单机（非 `GameMode` 3/4）且本机是观战者时，`Observer` 恒按本机房重建：

```
if (!联机 && Observer != 本机房 && 本机是观战者) Observer = 本机房;
```

单机只有本机一个观战者，语义无歧义；这一条同时覆盖"空""悬垂""错位"三种读档后
状态。联机不碰：`Observer` 是各端跑同一套选举得到的全局值，改它跨机分叉；联机
读档后 `Observer` 失效属原版缺陷，本模块不救。

## 8. 读档后"AI 被击败就结束对局"

### 落旗链条

`AcceptDefeat(0x4FC0B0)` 末尾内联着 `MPlayer_Defeated`，整段都在这个函数里：

| 位置 | 干什么 |
|---|---|
| `0x4FC3D9` | 打 `MPlayer_Defeated() - <房名> has been defeated` |
| `0x4FC3E6` | 评估段开头：数存活房（跳过 `Country+0x1A6` 非 0 的）→ 打 `Alive=.. Humans=..` |
| `0x4FC551` | 存活房两两全同盟 → 打 `Saw game completion due to player defeat` |
| `0x4FC591` | 看 `CurrentPlayer->Defeated`：0 → `Flag_To_Win`，非 0 → 往下走 |
| `0x4FC676` / `0x4FC69B` | 调 `Flag_To_Lose(0x4FCBD0)`；`0x4FC6A2` 调 `Flag_To_Win(0x4FC9E0)` |

房上连着排四个终局标志（`HouseClass`）：`+0x1F5 Defeated`、`+0x1F6 IsGameOver`、
`+0x1F7 IsWinner`、`+0x1F8 IsLoser`；"借来的时间"计时器在 `+0x298`
（CDTimerClass）。`Flag_To_Lose` / `Flag_To_Win` 只置各自的位 + 起一口计时器，
真正收场在 `HouseClass::Update` 的 `0x4F8657` 段：计时走完 → `IsWinner` 清 0，
`GameMode` 非 3/4 时 **本机房 → `[0xA83D49]`、其它房 → `[0xA8ECD0]`**。
主循环 `0x55D059` 看到任一面旗非 0 就收场：

| 旗 | 地址 | 谁写 | 含义 |
|---|---|---|---|
| `END_LOSE` | `0xA83D49` | `0x4F8692` | 本机出局，直接退 |
| `END_SCORE` | `0xA8ECD0` | `0x4F86F7` | 对局结束，弹结算 |
| `END_QUIT` | `0xA83D48` | `0x4C7917`（ESC 菜单） | 用户主动退出 |
| `END_EXIT` | `0x8B41C0` | `0x48CB2E`（关窗） | 退出程序 |

### 为什么读档后才暴露

观战房的 `+0x1F5 Defeated` **从开局就是 1**（它不参赛），所以 `0x4FC591` 永远走
"本机已战败"，任何 AI 出局都会给观战房落 `Flag_To_Lose`。正常局靠 `Flag_To_Lose`
开头那道早退躲过：`+0x1F6 IsGameOver` 已置位就直接 return，计时器不启动。读档后
`IsGameOver` 不恢复（为 0），早退失效 → 起 90 帧计时 → 1.5 秒后收场。

### 修法

钩 `0x4FC3E6`（6 字节 `xor edi,edi` / `xor ebx,ebx` / `test eax,eax`，前一条
`add esp,8` 已把日志参数清干净，栈是平衡的）。观战者直接跳到函数尾声 `0x4FC6BC`
（`pop edi/esi/ebp/ebx; add esp,0xB0; ret`），不落任何胜负旗。

- 判据 `OB_DefeatGuardArmed()`：**非联机** + `CurrentPlayer == Observer` 且在房表里
  + 本机房是观战者。普通对局 / 战役 / 联机一律返回 0 原样重放。
- 评估段之前的东西照常跑：战败房清理、`Opponent X has been defeated` 提示、侧栏刷新。
- 日志：`obs def skip: house=<观战房>`，同一个房只记一次，用来确认钩子确实生效。
- 别再试"在 `Observer_Poll` 里清这两面旗"：引擎在同一帧里落位并检查，轮询看不到。
