# 观战 / 多观战

## 1. 核心机制

| 量 | 地址 | 含义 |
|---|---|---|
| `HouseClass::Observer` | `[0xAC1198]` | 全局单例“真观战”房 |
| `HouseClass::CurrentPlayer` | `[0xA83D4C]` | 本机玩家房（各机不同） |

判据是 `IsCurrentPlayerObserver() = CurrentPlayer == Observer`。

## 2. 选举点：`ScenarioClass::AssignHouses` (0x687F10)

按 Color 升序遍历节点表（items `[0xA8DA78]` / count `[0xA8DA84]`），每轮建一个房：

```
0x687F4D  Observer 先清零
0x688109  仅下标 0 的节点被选中时写 CurrentPlayer
0x68813A  node->HouseIndex(+0x6F) = house->ArrayIndex(+0x30)
0x68811C  每个观战节点房都写一次 Observer
```

每建一个观战房就覆盖一次 Observer，最终只留最后一个。
只有那台机器满足 `CurrentPlayer == Observer`。

节点表字段（`NodeNameType`）：`SpectatorFlag +0x6B`（-1 为观战）、
`HouseIndex +0x6F`、`Color +0x53`。

战役（GameMode==0）走另一条路（`0x68ACE0`，按 INI 玩家名找房），不碰 Observer。

## 3. 为什么其余观察者“被击败”

观战房无单位无建筑，`House::Update`（`0x4F8E86` 起）必走
`DestroyAll` + `AcceptDefeat(0x4FC0B0)`。`AcceptDefeat` 内的观战豁免
全是“本机是真观战 / 战败的是真观战房”这类 UI 分支，假观战全走普通玩家分支。

## 4. 解法：只改本机 `CurrentPlayer`

```
if (本机确实是观战者 && CurrentPlayer != Observer) CurrentPlayer = Observer;
```

之后原版约 29 处观战分支自然命中，无需逐个挂钩。

约束：不改 `Observer`（全网一致，改它跨机分叉，波及胜负计数等模拟分支）；
不清 `Defeated(+0x1F5)`（模拟态，真观战同样为 1）。
`CurrentPlayer` 按定义各机本来就不同，对齐它不产生新分叉。

“本机确实是观战者”判据（需 `IsHumanPlayer(+0x1EC)`，两条取并集）：

* A. 节点表中有 `SpectatorFlag(+0x6B)==-1` 且 `HouseIndex(+0x6F)==ArrayIndex` 的节点。
* B. `ArrayIndex` 不在 `Scenario::HouseIndices`（`Scenario+0x1180`）内，即无出生点。

## 5. 观战面板排序：人类在前、AI 在后

面板名单表 `0x884B94` / 计数 `0x884CF8`，由 `0x6A57DC` 按 `HouseClass::Array`
顺序填充。原版跳过中立、跳过 Observer 自己、跳过全部 AI。
本模块改为：排除中立 / 任一观战槽（含自己）/ 野指针，其余先人类后 AI，
组内保持数组原序。引擎每帧重算，本模块每帧重填。

## 6. 验证

双机放 2+ 观察者：每台观战机都应看到观战面板；面板内人类玩家排在 AI 前面，
且任何占观战槽的玩家都不出现在面板上。
