# 地图格网显示

单机 `#` 按钮开关 (与暂停按钮同显同隐, 默认关): 视角停稳后画灰色格网 + 不可走提示。

## 做法 (逐格自有平面, 停稳重建)

* 每格存自家 4 角地面高度 (`CellClass::GetFloorHeight`, 角子坐标东/南取 255、
  西/北取 0, lepton mod 256, Ramp 格内插值靠它), 各投影一次 (`CoordsToClient`)。
* 不共享角点: 每格画自家 4 条边; 对侧同边两端屏坐标相同才跳过
  (平地只画一次; 悬崖画两条: 崖顶 + 崖底, 两端竖线连上下即崖面;
  斜向崖缘拼成阶梯)。
* 去重按格序号分边: 坐标相同时两格都会命中, 序号小的画 (否则平地线全丢)。
* key = 视口原点 + 视口尺寸 + 视图区 + 缩放 + 场景; 相邻两帧不一致判移动
  (隐藏旧缓存, 本帧不重建), 连 150ms 一致才重建。
  远缩整图超限 (160x160 / 20000 格) 记永久无效, key 变前不再试。
* 背面剔除 (`GridCullBack=1`): 高→低朝北/西的面背向镜头,
  高侧只留顶线、低侧不画 (Y 小者高, 两端同向差 3px 以上判台阶)。

## 不可走提示 (`GridShowBlocked=1`, 静态快照, 不管动态单位)

* 边画红: 硬挡 (`Passability==6`) / 悬崖图块 / 城墙覆盖物 / 矿覆盖物、
  73 格、真断崖 (两端屏差 >= 8px@1x, 按缩放折算); 与邻格任一红则共享边红。
* 覆盖物 70 (PALET01, 阻建造) 画叉, 73 (PALET04, 阻建造+通行) 画叉+内框。

## 配置 ([BottomBar])

* `GridCullBack=1` 悬崖背面剔除; `GridShowBlocked=1` 不可走提示。

## 地址 (只读)

* `GetFloorHeight=0x47B3A0`, `CoordsToClient=0x6D2140`,
  `Tile_Is_Cliff=0x4863D0` (不覆盖本图崖块, 断崖只走几何),
  `GetTiberiumType=0x5FDD20` (>=0 为矿)。
* `Cell+0x4C` 通行 / `+0x44` 覆盖物类型 / `+0x50` 城墙。

## 联机安全

* 只读查询 + 渲染面写入, 绘制只落视图区 A; 调用方仅单机跑
  (暂停模块门控, 见《暂停步进》)。
