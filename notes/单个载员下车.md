# 单个载员下车

选中载具或驻军建筑后，信息面板第 2 格起是载员图标。点其中一个图标，只让那一个下车/离开建筑。

配置：`[Features] SingleUnload`（默认 1）。关掉只是面板点击不再发单卸事件，钩子仍在，联机结论不受影响。

## 载具

- 载员链：`PassengersClass { int NumPassengers@0x114; FootClass* FirstPassenger@0x118 }`，链走 `ObjectClass::NextObject@0x30`。
- 载员的 `FootClass::Transporter` 在 **0x11C**（运行时实证：车下载员此处 == 载具指针，载具自己为 0）。`+0x5D4` 是另一套「容器」字段（驻军建筑 / 坦克掩体），车下载员恒为 0，不能拿它判载具归属。
- 原生 `UnitClass::Mission_Unload`（跳表槽 0x23C，函数 0x73D630）只有全放：状态 3 入口 0x73D8B7 每 tick 弹链头一个（0x73D8CD = `RemoveFirstPassenger` 0x4DE710），`NumPassengers <= NonPassengerCount(0x6E4)` 后跳 0x73DCAB 置状态 4。
- 单卸：事件仍发普通 `Mission::Unload`(16)，`Target.rtti = 0`、`Target.id = 0x534E0000 | 链序号`。引擎只在 rtti 非 0 时解析 id（0x4C7225），所以 id 是安全的自定义载荷。
- 钩子：
  - 0x4C7462 事件派发：认出载荷就记 (对象, 序号)；同对象后到的普通整批卸载令清掉旧记录。
  - 0x73D8B7 状态 3 入口：记录里那个已经不在链上 → 跳 0x73DCAB 收尾，一次任务只放一个。
  - 0x73D8CD 弹链头：有记录就改调 `RemovePassenger(0x4DE670)` 指定对象，EAX 回填后跳 0x73D8D2。
- 记录先判 `fired` 再判过期：弹完后必须一直收尾到状态 3 再进来为止，中途按帧数过期会把剩下的载员交回原生整批卸载。

## 驻军建筑

- 驻军存在 `BuildingClass::Occupants`：`DynamicVectorClass<InfantryClass*>` 本体 0x684，`Items` 0x688，`Count` 0x694（`GetOccupantCount` 0x4581F0 直接返回 `[ecx+0x694]`；0x4585C0 `KillOccupants` 读 Items/Count，0x522941 `AddOccupant` 用 `lea [ebp+0x684]` 实证）。和载具的 Passengers 链是两套存储。
- `BuildingClass::Mission_Unload` = **0x44D880**，与 `UnitClass::Mission_Unload`(0x73D630) 是同一个虚表槽（0x23C，按两套虚表各自起点算出的偏移一致）。人数 > 0 时调 `0x457DE0(0,0)` 全放。
- `0x457DE0` 流程：先在建筑周围找一个空位（`[occupant vtbl+0x1ac]` 探格），`[0xa8e7ac]++`，然后从 `Count-1` 倒序逐个 unlimbo 出去（`[vtbl+0x174](pos,1,1)`，有 0x5D4 容器就 `0x6EA870` 断开，再 `[vtbl+0x1e8](15,0)` 给 Hunt），循环后 `[0xa8e7ac]--`、清空向量、`[vtbl+0x1bc]` + `0x70f6e0` 刷新建筑动画。
- 单卸：同样的 `Mission::Unload` + magic id，序号改成 Occupants 向量下标。
  - 0x4580A9（循环头，ESI=建筑，EBP=下标）：有记录就只让记录里那个进原生放人流程，其它下标跳 0x45819D（`dec ebp; jns`）继续，驻军仍留在向量里。
  - 0x4581A4（循环收尾）：照原样 `[0xa8e7ac]--`（这个计数必须平衡），但不清空向量，只把放走的那个 `RemoveItem` 式移出（后面的前移、`Count--`），然后跳 0x4581C9 刷新动画。
  - 记录过期或下标已失效时，本次一个都不放（面板点击变成空操作），绝不回落到整批卸载。
- 面板显示：单选版式 cell0 = 建筑/载具、cell1 = 信息格、cell2 起 = Occupants 向量顺序 / Passengers 链顺序。载员超过 7 个时自动翻页（前两格每页固定，其余每页 7 个），页码点画在下边框带上，滚轮在面板上滚动即可翻页；超过 3 页时末页最后一格是「更多」。载员序号始终是整条向量/链上的下标，与面板当前页无关。

## 日志

```
su: pax idx=2 ...           载具点击，链序号与归属字段
su: bld idx=1 n=6 ...       建筑点击，向量下标与当前人数
su: click idx=2 f=...       已发单卸事件
su: ev16 rtti=0 id=...      事件派发，认出载荷
su: rec idx=2 f=...         记录建立
su: pop idx=2 f=...         载具弹人点换成指定载员
su: bld pop idx=1 f=...     驻军循环放走指定下标
su: done idx=2 f=...        载具收尾
su: bld done idx=1 f=...    驻军收尾，向量已移除
su: bld miss idx=1 f=...    收尾时向量对不上（下标失效），什么都没放
su: bld expire idx=1 f=...  记录过期，本次不放
```
