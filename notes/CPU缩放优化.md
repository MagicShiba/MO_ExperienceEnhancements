# CPU RGB565 缩放优化

仅迁入 CPU 像素缩放优化，不包含 GPU 实验模块、配置、钩子、UI 合成、光标、缓冲构造或渲染事务修改。

- 精确2:1最近邻行采样：局部SSE2内核，运行时检查支持，旧CPU保留标量路径；不改变项目最低指令集。
- 通用最近邻：按步长、裁剪起列、输出宽度缓存列映射；四像素展开；重复源行复制已采样目标行。
- 主视口与PiP scale=2复用行内核。保留原unsigned16.16映射、裁剪及已有整数放大快路。
- 1x原有分派不改，不增加采样、快照或上传；不改变模拟、网络、输入和引擎调用顺序。

代码范围：新增Resample565.h/.cpp，ScaleBar.cpp和PiP.cpp最小接入。测试保留行内核和完整目标像素等价检查，不能以微基准倍数推算游戏FPS。

GPU实验完整历史和清理结果保留在experiment/gpu-compositor分支；实验版本笔记已合并为该分支的notes/GPU合成试验.md，不带入CPU主分支。
