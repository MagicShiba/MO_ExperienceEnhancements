# 欢呼 (C 键)

代码 `src/misc/CheerSelect.cpp`,钩 `0x730F30`,ini `[Features] CheerSelected`。

## 1. 为什么原版是"全体"

按键 → 事件 → 遍历本家全部 Techno:

```
0x6D074C  cmp eax,[0xB0C1B8]   ; AllToCheer 键码 (KeyboardMD.ini 默认 67='C')
0x6D0754  call 0x730F30        ; AllToCheerCommandClass::Execute
```

`AllToCheerCommandClass::Execute` @ `0x730F30`(`void`,尾部 `add esp,0x70; ret`):

```
730f30: mov eax,[0xA8B538]     ; MuteSWLaunches, 非 0 直接返回 (静音不欢呼)
730f35: sub esp,0x70
730f3a: jne 0x730FD8           ; -> return
730f40: eax = RulesClass
730f45: edx = [0x84555C]       ; 上次全局欢呼的帧号 (静态, 初值 -100)
730f4b: ecx = [Rules+0x580]    ; MaximumCheerRate (MO 里 300 逻辑帧)
730f58: cmp ecx+edx, eax       ; 有符号, 与当前帧号比
730f5a: jge 0x730FD8           ; 冷却未到 -> 什么都不做
730f62: push 0x2D              ; EventType::ALLCHEER (45)
0x4C6CB0 EventClass::Execute 表下标 = Type-1, 第 44 项 0x4C6E2E
  -> call 0x50C8C0             ; HouseClass::Cheer()
730fce: [0x84555C] = 当前帧号
```

`HouseClass::Cheer` @ `0x50C8C0`:遍历全局 Techno 表 (`items=[0xA8EC7C]`,
`count=[0xA8EC88]`),对 `Owner == this` 的每个 Techno 调
`vtable[0x388](false)`,最后播一次 `CheerSound`(`Rules+0x1C8`,pan 0x2000)。
**"全局"只是这层遍历,单位级入口本来就有。** 另有 `TAction::Cheer` @ `0x6E3060`
(脚本动作 0x71)走同一条。

## 2. 单位级入口: 只有步兵会真欢呼

| 虚表槽 | 基类 | InfantryClass |
|---|---|---|
| `0x384` `CanCheer()` | `0x41BF80` = `return false` | `0x522BC0` |
| `0x388` `Cheer(bool Force)` | `0x41BF90` = `ret 4` 空实现 | `0x522C00` |

`CanCheer`:Mission 必须是 Guard(5)/Area_Guard(11),且当前 Sequence 是
Ready(0)/Idle1(9)/Idle2(10)/Cheer(32)。`Cheer`:`Force=0` 时先问 `CanCheer`,
过了就播 `Sequence::Cheer`(32)。

- 载具/飞机/建筑这两个槽都是基类实现,按 C 键毫无反应 —— 原版行为。
- `Cheer` 不动 Mission、不发事件、不写模拟字段,只换渲染序列(及序列自带语音)。

## 3. 已实施: 局部欢呼

钩 `0x730F30` 8 字节(`mov eax,[0xA8B538]` + `sub esp,0x70`,整条重放无 rel)。
判定顺序:配置关 → 原版;联机 → 原版;`MuteSWLaunches` → 原版;无选中 → 原版。

有选中时遍历 `CurrentObjects`(`0xA8ECB8`,数组 `0xA8ECBC`,计数 `0xA8ECC8`),
只挑 `WhatAmI==Infantry` + 本家 + 活着 + 非 InLimbo,逐个 `vtable[0x388](0)`;
至少一个就照 `HouseClass::Cheer` 收尾播一次 `CheerSound`。一个能欢呼的都没有
也消费掉按键(不回落全局),否则"选中即范围"不成立。

- **返回 `0x730FDB`**:那是函数尾部 `add esp,0x70` 之后那条裸 `ret`。本模块没
  分配栈帧,必须跳 `ret` 而不是 `0x730FD8`。
- **不读不写 `[0x84555C]`**,也不给局部欢呼加冷却/去重。占了那个戳会表现为
  "局部欢呼过一次 → 再取消选中按 C 也按不出全局"。
- 联机一律回原版:`Cheer` 本地执行不会造成不同步,但 `ALLCHEER` 事件是"让对手
  也看到你方欢呼"的唯一通道,`MEGAMISSION` 的 Mission 枚举里没有 Cheer,
  没有"部分"版本的事件可用。
