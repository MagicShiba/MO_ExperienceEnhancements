# 攻击范围显示（WeaponRange）

单选 1 个单位（Unit/Infantry/Aircraft）且按住 Ctrl，在 Composite 面上画圈。
`[Features] WeaponRange` 总开关。全只读 + 渲染面绘制，联机安全。

| 圈 | 颜色 | 数据 |
|---|---|---|
| 地面最大 | 蓝实线 | 当前武器 `Range` |
| 最小 | 红实线 | `MinimumRange`（0 不画） |
| 对空 | 青虚线 | 对空武器 `Range` + `AirRangeBonus` |
| 部署作用 | 绿实线 | 部署武器弹头 `CellSpread`（读不到回落武器 `Range`） |
| 隐形探测 | 黄实线 | `SensorsSight`（0 不画） |
| 间谍识别 | 紫实线 | `DetectDisguiseRange`（0 不画） |

当前武器 = `CurrentWeaponNumber` 下标 + 精英换 `EliteWeapon`；对空在下标 0/1
里找（威胁位 `Air` 位）；部署按 `DeployFireWeapon`（0=主，1=副，缺键默认 1）。
占位扫描器（`VirtualScanner` 等，按名 + 低伤害）不参与对空搜索。
所有单位（含飞行/悬浮）圆心统一取自身 X/Y 处的地面投影，不考虑自身 Z：地形高度用
`MapClass::GetCellFloorHeight`（`0x578080`），若该格有桥且单位更接近桥面则加桥高
（`CellClass::BridgeHeight` = 4×104），桥下单位仍取地形。半径不做地形修正，也不考虑
高处/地形起伏带来的额外射程变化。

`[Features] WeaponRangeAAZ`：对空圈高度（lepton，1 格=256）。0=贴地；非 0=抬到该假设
高度，推荐 600。常用飞行兵/载具直升机 `JumpjetHeight` 多为 500~650；机场飞机
`FlightLevel=1200` 不适用。

## 取数（地址/偏移 + 证据）

| 数据 | 取法 | 证据 |
|---|---|---|
| 单位类型 | Unit/Aircraft `+0x6C4`，Infantry `+0x6C0`，`TechnoType` 数组 `0xA8EB00` 做 `InTypeSet` 校验 | ToolTip/DeployPreview 同式 |
| 武器 | `TechnoType::GetWeapon(0x7177C0)` / `GetEliteWeapon(0x7177E0)`，回 `WeaponStruct*`，首 dword 即 `WeaponType*` | `Weapon[0]` 实测偏移 `0x898` 与手算一致 |
| 精英/下标 | Techno 内 Owner 指针锚定：`+4` 浮点 `[-0.5,3]` 为 `Veterancy`（≥2 精英），`-20` 为下标，`-16` 为军衔；找不到退化 0/0 | 日志 `elite=` |
| `Range`/`MinimumRange` | `WeaponType` 内相邻 int 对，运行时投票 pin（多把武器一致，`rangeOff=` 日志，正常 180） | 狗牙 468=1.83 格、心控 2048=8 格 |
| 对空判定 | `WeaponType::AllowedThreats(0x772A90)` 的 `Air(0x4)` 位；函数内部先取 `[WeaponType+0xA0]` 弹头再读弹头 `+0x2A4` | 反汇编；狗牙 `th=184` 无 Air，堡垒导弹 `th=188` 有 |
| `AirRangeBonus` | `TechnoType+0x68C`，int 轻子数（与 `Range` 同制）；`Weapon[0]` 偏移 `0x898` 且 `Elite[0]` 差 `0x1FC` 双锚，不符则无加成 | GGI 标称 3 格实测 768 |
| 探测/识别 | `SensorsSight +0x5F0`，`DetectDisguiseRange +0x5F4`，int 格 | 警犬 `dis=7` |
| 部署门/序号 | `DeployFire +0x6AC`（0/1），`DeployFireWeapon +0x6A8`（0/1） | 心灵专家/辐射工兵读 1，自爆卡车读 0 |
| 地表高度 | `MapClass::GetCellFloorHeight(0x578080)` 按 X/Y 采子格；桥格再加 `CellClass::BridgeHeight` | Phobos `Hooks.UI.cpp:716` 同用 |
| 弹头 spread | 弹头指针在 `Range-8`，`CellSpread` 为 `WarheadType+0x124` float 格 | 心灵震爆 3.3、辐射爆发 9.5、自爆 8 |
| 注册名 | 类型/武器 ID 自校准（候选 `0x20/0x24/0x28`，字符集校验），日志 `tid=`/`wid=` | ADOG/DogBite 等 |

## 三个会再踩的坑

### 1. `AllowedThreats` 的 ECX 是武器，不是弹头

`0x772A90` 开头就是 `mov ecx,[ecx+0xA0]`（取弹头）。传弹头进去会在 `+8`
处空读崩溃（`mov dl,[ecx+0x2A4]`，ecx=0）。只判 `Air` 位，不加数值上限
（掩码最大位 `0x10000`）。

### 2. `IsPlausiblePtr` 不能 guard 单字节读

它要求 4 字节对齐，`+0x6AD` 这类地址恒返回 0。`DeployFire` 这类单字节直接
读（x86 非对齐读安全，对象已校验）。

### 3. `Damage` 不能当占位判据

心控（1）、辐射爆发（1）等真武器伤害也是 0/1。占位只认武器名精确匹配
（搜索/部署分支）+ 搜索分支伤害 backstop；当前武器分支不过滤。
