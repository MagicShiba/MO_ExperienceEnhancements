# 侵略模式 (Alt+A)

## 目标

给单位一个"侵略"标记: 标记期间, 单位**闲置**时会自动对**警戒范围内**的
**敌方建筑**下令 (补原版只在武器射程内自动索敌的盲区)。订单**与鼠标左键同判**:
作战单位攻击、工程师占领。标记中的单位在头顶画 `icon_aggressive.png` 图标。
Alt+A (可配) 切换选中单位的标记。

## 用法

* Alt+A: 选中若干作战单位, 按一下加入标记; 若选中的单位**全体**都已在标记里,
  再按一下就整体移出 (标准组开关语义)。
* 配置见 `[Aggressive]` (dist/MOExperience.ini)。

## 判定口径

* **标记集合**: 本机 UI 状态 (同 MindSelect 的选中), 用 `Fetch_ID` 认身份,
  指针/存活每轮复核, 死了自动剔除。换家 (观战切位/换图) 清空。
  只收本家 (Owner==CurrentPlayer) 的作战单位 (Unit/Infantry/Aircraft)。
* **闲置**: 当前 Mission ∈ {Guard(5), Area_Guard(11), Stop(13)}
  (虚表槽 0x184 取 Mission)。
* **攻击半径**: 先取 `GetGuardRange(0)` @ **0x707E60** (纯读, thiscall) 返回的
  类型 `GuardRange` 原值 (未设回 0); 若为 0 则回退到主/副武器射程较大者
  `GetWeaponRange(0/1)` (**0x168** 虚表槽, 实现 @ 0x7012C0)。
  再乘 `RangePercent`% (默认 100, 10~400)。只用这个半径内的建筑当候选。
  * **不可用 `GetGuardRange(1)`**: 它把半径加倍后以 **4096 轻子(16 格)封顶**
    (control=0 原值 / 1 加倍+封顶 / 2 巡逻 1792~4096, 见 YRpp:244), 所以
    无 GuardRange 的远射程单位会被截断到 8 格。旧实现 `/2` 即受此害。
* **目标**: 存活/**敌方** (忽略中立) 的 `BuildingClass`。先按圆心水平距离由近到远,
  只对"比当前最优更近"的候选调 `AG_UnitMission` (只读光标) 复核订单; 取最近的有效目标。
  距离用 64 位平方和 (避免 32 位溢出)。
  * 中立判定 `House->Type(+0x34)->MultiplayPassive(+0x1A6)` (SmartArea 同式);
    自检: 本家不可能是被动中立, 读出 1 则永久停用过滤 (回"非本家即目标")。
    无主建筑 (Owner 为空) 一律不算候选。
* **订单 = 鼠标对应的事件** (`AG_UnitMission`): 取该单位对该建筑的**固有光标**
  (`OU_MouseOverObjectNative`, ignoreForce=1, 无视修饰键) → Mission
  (攻击1/占领8; 与 SmartOrder/SmartArea 同表), 其余/未知回 -1 (不下单)。
  发令时: 攻击走 `Target=敌对象`; 占领走 `Target=空, Destination=对象`
  (与手点建筑的真实事件布局同形)。
  * **不做单位类型特判**: 工程师占领、劫持 (抢敌载具) 等一律按实际左键光标,
    光标是攻击就攻击、是占领就占领, 免维护逐类型分支, 也不会被盲区逻辑带偏。
  * 进入/进驻 (Mission 7/17) 是自家步兵进空楼, 对敌方建筑不成立, 不做映射。
  * 打不了的目标 (光标 NoMove/Repair 等) 不下单。
* **发令**: 一条标准 MegaMission (攻击: `Mission=Attack`, Target=敌建筑, Dst 空;
  占领: `Mission=Capture`, Target 空, Destination=敌建筑;
  均 `IsPlanningEvent=0`), 经 `OT_Fire` (联机 mode=2 分帧, 否则 `OU_Enqueue`)。
  滴发前重算一次订单 (只读光标复核), 状态变了 (打不着/改占领) 就丢。

## 节奏

* `Interval` (默认 15 帧) 扫一次; `Cooldown` (默认 45 帧) 内同一单位不重复发令。
  命中目标后排进待发队列, 每循环最多 128 条滴发 (OutList 一帧上限 128)。

## 联机安全 (AGENTS.md 铁律)

* 不写任何模拟内存, 不直调改模拟的引擎函数。
* 标记集合是本机状态, 各端各管各的。
* 唯一模拟变更 = 标准攻击/占领事件入 OutList, 各端执行同一份原版代码 ——
  与玩家自己手点同一目标逐字节同形。

## 图标

* 这是**独立地图图像**, 与文字字形图标 (`icon_cost`/`icon_power_*` 等走 Icon.h/
  Icon.cpp 的 PUA 字形; 见 mkicons.py 的 GLYPHS) 分开, 不占 PUA 码、不进字形表。
* `icons/icon_aggressive.png` (11x11 RGBA) 由 `icons/mkicons.py` 转成
  `icons/mapicons.inc` (保留原图 RGBA), 对应 `icons/IconMap.h/.cpp`
  (槽 `MAPICON_AGGRESSIVE`); 改图后手动跑一次 mkicons.py。
* 图像直接 blit 到已锁定的 16 位渲染面 (`IconMap_Blit`, 按像素 RGB+alpha 混合),
  不进文字、不受墨色影响。位置 = 单位中心投影 + 像素偏移 (居中锚定)。
* 绘制挂 `MOE_DrawUILayers` (WeaponRange 之后), 只读投影经 `OU_ProjWorld`。

## 关键地址 (只读)

* BuildingClass::Array 0xA8EB40 (Items@+4/Count@+16); Owner 0x21C;
  IsAlive 0x90 / InLimbo 0x81 / Health 0x6C; Mission 0xAC (槽 0x184);
  Frame 0xA8ED84; Fetch_ID 索引 0xB0E840 (见 OrderUtil.h)。
* 中立 `House->Type(+0x34)->MultiplayPassive(+0x1A6)` (与 SmartArea/Observer 同式)。
* GetWeaponRange: **虚表槽 0x168** (0=主武器 1=副武器), 实现 @ **0x7012C0**
  (thiscall, `ret 4`, 返回轻子; 全部 TechnoClass 系 vtable 该槽同址无覆盖)。
  Ares 钩内层 0x70133E / Phobos 钩 0x7012C2。
* GetGuardRange 入口 @ **0x707E60** (头 `push ebx/esi/edi`)。Phobos Hooks.cpp:1997
  钩的是内层 0x707E63 (prologue 之后, 用 STACK_OFFSET(0xC,4) 补 3 个 push),
  **不能**把 0x707E63 当入口直接调 —— 会跳过 3 个 push, 函数尾 `pop edi/esi/ebx;
  ret 4` 弹错 → 野跳崩溃。
