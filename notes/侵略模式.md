# 侵略模式 (Alt+A)

## 目标

给单位一个"侵略"标记: 标记期间, 单位**闲置**时会自动对**警戒范围内**的
**敌方目标**下令 (补原版只在武器射程内自动索敌的盲区)。订单**与鼠标左键同判**:
作战单位攻击、工程师占领。标记中的单位在头顶画 `icon_aggressive.pcx` 图标。
Alt+A (可配) 切换选中单位的标记。

目标范围由 `[Aggressive] Target` 决定: `all` = 建筑 + 步兵/载具/飞机 (默认),
`building` = 只打敌方建筑。"全部"让不主动索敌的支援/攻城单位也去清理野战目标。
设置页把它和热键并成一行: 快捷键页 → 侵略模式 → 左边两段选范围, 右边改热键。

## 用法

* Alt+A: 选中若干作战单位, 按一下加入标记; 若选中的单位**全体**都已在标记里,
  再按一下就整体移出 (标准组开关语义)。
* 配置见 `[Aggressive]` (dist/MOExperience.ini)。`Target` 也能在设置页改
  (快捷键页 → 侵略模式行左边的 仅建筑 / 所有敌方单位)。

## 判定口径

* **标记集合**: 本机 UI 状态 (同 MindSelect 的选中), 用 `Fetch_ID` 认身份,
  指针/存活每轮复核, 死了自动剔除。换家 (观战切位/换图) 清空。
  只收本家 (Owner==CurrentPlayer) 的作战单位 (Unit/Infantry/Aircraft)。
* **闲置**: 当前 Mission ∈ {Guard(5), Area_Guard(11), Stop(13)}
  (虚表槽 0x184 取 Mission)。
* **攻击半径**: 取三者中的最大值 —— `GetGuardRange(0)` @ **0x707E60** (纯读,
  thiscall) 返回的类型 `GuardRange` 原值 (未设回 0), 与主/副武器射程
  `GetWeaponRange(0/1)` (**0x168** 虚表槽, 实现 @ 0x7012C0)。
  只按 GuardRange 会够不到"警戒圈小于真射程"的单位能打的目标。
  再乘 `RangePercent`% (默认 100, 10~400)。只用这个半径内的目标当候选。
  * **不可用 `GetGuardRange(1)`**: 它把半径加倍后以 **4096 轻子(16 格)封顶**
    (control=0 原值 / 1 加倍+封顶 / 2 巡逻 1792~4096, 见 YRpp:244), 所以
    无 GuardRange 的远射程单位会被截断到 8 格。
* **候选**: 存活/**敌方** (忽略中立) 的对象。`Target=all` (默认) 收
  `BuildingClass::Array` 与 `UnitClass::Array` (0x8B4108) / `InfantryClass::Array`
  (0xA83DE8) / `AircraftClass::Array` (0xA8E390) 里 `OU_IsUnit` 通过的对象;
  `Target=building` 只收建筑数组。建筑优先收, 表满 4096 就不再收单位。
  四个数组各有一道"两帧不变"稳定门。
  * 先过一道**"光标点得到"闸** (`AG_Clickable`, 与引擎命中判定同判): 看不见的
    隐形单位光标落不上去, 攻击令发下去也会被引擎自己清目标 (`0x414D79`:
    `Target->CloakState==2` 且 `Target->vt+0x32C(自己 Owner)` 为假 → `SetTarget(0)`),
    单位只会站着发呆。判据照抄 `0x6DA380` / `0x692300`: `[obj+0x41A]` 置位放行;
    否则 `CloakState(obj+0x220)==2` 时要求本家探测器覆盖该格
    (`Cell->Sensors_InclHouse`), 类型 `InvisibleInGame` (`type+0xC9A`) 一律排除。
    过滤只在候选收集做一次（不逐单位查），"最近优先"才不会锁死看不见的目标。
  先按圆心水平距离由近到远, 只对"比当前最优更近"的候选调 `AG_UnitMission`
  (只读光标) 复核订单; 取最近的有效目标。距离用 64 位平方和 (避免 32 位溢出)。
  * 中立判定 `House->Type(+0x34)->MultiplayPassive(+0x1A6)` (SmartArea 同式);
    无主 (Owner 为空) 的对象不算候选。
* **订单 = 鼠标对应的事件** (`AG_UnitMission` = `OU_NativeMission`): 取固有光标
  (`OU_MouseOverObjectNative`, ignoreForce=1) → `OU_RemapAction` → FootClass
  Action→Mission 表。攻击走 `Target=敌对象`；进驻/占领/破坏走 `Target=空,
  Destination=对象`。
* 不做单位类型特判。步兵对建筑会把 `Damage` 翻成 `Capture`，必须照做，
  否则工程师会误发攻击。订单逻辑与 SmartOrder/FuzzyAttack/AttackMove 共用。
* 打不了的目标（光标 NoMove/Repair 等）不下单。
* **发令**: 一条标准 MegaMission (攻击: `Mission=Attack`, Target=敌目标, Dst 空;
  进驻/占领/破坏: `Mission=Enter7/Capture8/Sabotage17`, Target 空, Destination=敌目标;
  均 `IsPlanningEvent=0`), 经 `OT_Fire` (联机 mode=2 分帧, 否则 `OU_Enqueue`)。
  滴发前重算一次订单 (只读光标复核), 状态变了 (打不着/改占领/目标隐形) 就丢。

## 节奏

* `Interval` (默认 15 帧) 扫一次; `Cooldown` (默认 45 帧) 内同一单位不重复发令。
  命中目标后排进待发队列, 每循环最多 128 条滴发 (OutList 一帧上限 128)。

## 联机安全 (AGENTS.md 铁律)

* 不写任何模拟内存, 不直调改模拟的引擎函数。
* 标记集合是本机状态, 各端各管各的。
* 唯一模拟变更 = 标准攻击/占领事件入 OutList, 各端执行同一份原版代码 ——
  与玩家自己手点同一目标逐字节同形。

## 图标

* `icon_aggressive.pcx` 是独立地图图像，不占文本字形的 PUA 码。
* 必须是 **3 plane 24-bit RGB** PCX，透明处填洋红，`(0,0)` 即色键。
  4 plane RGBA 引擎会按 3 plane 误读，不支持。
* 源文件在 `icons/`。改图标后手动运行 `python icons/pcx_tool.py` 归一化
  （RGBA 转 3-plane RGB，透明填洋红；文字图标转 1-plane 8bpp），再构建。
  `src/gui/icons.rc` 把 PCX 作为 RCDATA 编进 `MOExperience.dll`；运行时把
  资源写到临时文件，`ForceLoadFile(...,1,0)` 读入 16 位面后删除。
* 绘制挂 `MOE_DrawUILayers` (WeaponRange 后)，位置=单位中心投影+像素偏移。
  贴图不走引擎 blit 而走 `PcxImage_DrawClip`：逐像素拷、跳 key 色，只写图像与
  `OU_ViewClip` 的交集 —— 底栏/侧栏不是每帧重画，交给引擎 blit 会留残影。
  越界坐标不夹取，屏外单位不会把图标贴到视口边缘。每帧只查一次面表，真正
  加载只在首次。
* 引擎 PCX 名称表按小写键查找，临时路径统一转小写。`Icon_Preload` 在首次
  UI 绘制时预取文字图标和侵略图标。

## 关键地址 (只读)

* 对象类型数组 (Items@+4/Count@+0x10): Building 0xA8EB40 / Unit 0x8B4108 /
  Infantry 0xA83DE8 / Aircraft 0xA8E390; Owner 0x21C;
  IsAlive 0x90 / InLimbo 0x81 / Health 0x6C; Mission 0xAC (槽 0x184);
  Frame 0xA8ED84; Fetch_ID 索引 0xB0E840 (见 OrderUtil.h)。
* 中立 `House->Type(+0x34)->MultiplayPassive(+0x1A6)` (与 SmartArea/Observer 同式)。
* 隐形可见性 (全只读): `CloakState` = Techno`+0x220` (Cloaked=2, 写入点 0x454E85);
  `CellClass::Sensors_InclHouse` @ **0x4870D0** (`cell+0x7C+idx*2 > 0`, 索引 =
  `HouseClass::ArrayIndex` +0x30, 只有前 24 个玩家); `Display::GetCellAtCoords`
  @ **0x565730** (坐标→Cell, 越界回占位格 0xABDC50); `type+0xC9A` = 由
  `InvisibleInGame` 派生的"点不到"标记 (解析点 0x460E09); `Techno+0x41A` = 命中
  豁免标记 (语义未定, 全 exe 7 处引用都是"置位则跳过隐形检查", 照抄)。
* GetWeaponRange: **虚表槽 0x168** (0=主武器 1=副武器), 实现 @ **0x7012C0**
  (thiscall, `ret 4`, 返回轻子; 全部 TechnoClass 系 vtable 该槽同址无覆盖)。
  Ares 钩内层 0x70133E / Phobos 钩 0x7012C2。
* GetGuardRange 入口 @ **0x707E60** (头 `push ebx/esi/edi`)。Phobos Hooks.cpp:1997
  钩的是内层 0x707E63 (prologue 之后, 用 STACK_OFFSET(0xC,4) 补 3 个 push),
  **不能**把 0x707E63 当入口直接调 —— 会跳过 3 个 push, 函数尾 `pop edi/esi/ebx;
  ret 4` 弹错 → 野跳崩溃。
